## 1. 用 $\Theta$ 表示 $f(n) = n^3 + 3^n + 2^n$

分析各项：
- $n^3$ 为多项式增长，$\Theta(n^3)$
- $2^n$ 为指数增长
- $3^n$ 也是指数增长，且 $3^n$ 增长速度远快于 $2^n$

由于 $3^n$ 是增长最快的项，故 $f(n) = \Theta(3^n)$。

## 2. 问题计算复杂度与算法时间复杂度

**问题的计算复杂度**（下界）：指解决某问题**所有可能的算法**中，最坏情况下所需的最小代价（时间/空间）。它是问题的固有属性，是任何算法都不可能逾越的下界。例如，基于比较的排序问题下界为 $\Omega(n\log n)$。

**算法的时间复杂度**（上界）：指**某个特定算法**运行所需的时间随问题规模 $n$ 增长的趋势，用 $O$、$\Theta$、$\Omega$ 等记号表示。例如，快速排序的时间复杂度为 $O(n^2)$，期望 $O(n\log n)$。

**关系**：算法复杂度给出了问题的上界；问题复杂度给出了算法的下界。当二者匹配时，说明该算法是渐近最优的。

## 3. NP 完全问题

**NP 完全问题（NPC）** 需同时满足两个条件：
1. 该问题属于 NP（非确定型多项式时间可解/多项式时间可验证）。
2. 该问题是 NP-hard 的（所有 NP 问题都能多项式时间归约到它）。

若任意一个 NPC 问题存在多项式时间算法，则 P = NP。典型例子：SAT 问题、旅行商问题（TSP）、图的顶点覆盖问题、子集和问题等。

## 4. 最优子结构性质

**定义**：如果一个问题的最优解包含其子问题的最优解，则称该问题具有最优子结构性质。

**意义**：最优子结构是使用**动态规划**和**贪心算法**的前提条件。利用该性质，可以通过子问题的最优解递归地构造原问题的最优解，从而避免枚举所有可能解（暴力搜索），大幅降低算法复杂度。

例如：
- 最短路径问题：$s$ 到 $t$ 的最短路径上任意中间点 $m$，$s \to m$ 和 $m \to t$ 的路径也是最短的。
- 矩阵链乘法：最优加括号方式的子括号方式也是最优的。

## 5. 随机算法的两类及其特点

### (1) Las Vegas 算法
- **特点**：总是返回正确结果，但运行时间是随机的。
- **评价标准**：期望运行时间。
- **例子**：随机化快速排序（随机选主元）、随机化选择算法。

### (2) Monte Carlo 算法
- **特点**：运行时间是确定性的（或在一定时间后终止），但结果可能不正确，有一定的错误概率。
- **评价标准**：错误概率和运行时间的权衡。
- **例子**：随机素数测试（Miller-Rabin）、蒙特卡洛积分。

| 类型 | 正确性 | 时间 |
|------|--------|------|
| Las Vegas | 绝对正确 | 随机 |
| Monte Carlo | 可能有错 | 确定/有界 |

## 7. 判断递增数组中 $a[i] = i$ 的算法

### 核心思想

由于数组是递增排序的，可以利用二分查找。考虑差值 $a[i] - i$，该函数是非递减的（因为 $a[i]$ 递增，$i$ 也递增但速度固定，$a[i+1] - (i+1) \geq a[i] - i$）。

二分搜索满足 $a[i] = i$ 的元素。

### 伪代码

```
Algorithm FindEqualIndex(A[1..n])
Input: 递增排序数组 A
Output: 是否存在 A[i] = i, 存在则返回 i

1. low = 1, high = n
2. while low <= high:
3.     mid = (low + high) / 2
4.     if A[mid] == mid:
5.         return mid  // 找到
6.     else if A[mid] < mid:
7.         low = mid + 1  // A[i] < i, 找右边
8.     else:
9.         high = mid - 1  // A[i] > i, 找左边
10. return -1  // 不存在
```

### 时间复杂度

二分查找，每次将范围缩小一半，时间复杂度为 $O(\log n)$，这是该问题的最优复杂度。

## 8. 判断 A 是否是 B 的子序列

### 核心思想

子序列不要求连续，但要求保持相对顺序。使用双指针：一个指向 A，一个指向 B，贪心地在 B 中按顺序匹配 A 的每个元素。

### 伪代码

```
Algorithm IsSubsequence(A[1..m], B[1..n])
Input: 数组 A (长度 m), B (长度 n), m < n
Output: A 是否是 B 的子序列

1. i = 1, j = 1  // i 指向 A, j 指向 B
2. while i <= m and j <= n:
3.     if A[i] == B[j]:
4.         i = i + 1  // 匹配成功, A 前进
5.     j = j + 1  // B 始终前进
6. return i > m  // A 的所有元素都匹配成功
```

### 时间复杂度

每个元素最多被访问一次，时间复杂度为 $O(m + n)$，由于 $m < n$，即 $O(n)$。

空间复杂度为 $O(1)$（仅使用常数个变量）。

## 9. 动态规划求数组中最长回文子串的长度

### 核心思想

定义 $dp[i][j]$ 表示子串 $A[i..j]$ 是否为回文。

状态转移：
$$dp[i][j] = \begin{cases} \text{true} & \text{if } i = j \\ \text{true} & \text{if } i+1 = j \text{ and } A[i] = A[j] \\ dp[i+1][j-1] & \text{if } A[i] = A[j] \\ \text{false} & \text{otherwise} \end{cases}$$

在填充 DP 表的过程中跟踪最大长度。

### 伪代码

```
Algorithm LongestPalindrome(A[1..n])
Input: 数组 A
Output: 最长回文子串长度

1. dp[1..n][1..n] = false
2. maxLen = 1
3. // 单个字符都是回文
4. for i = 1 to n:
5.     dp[i][i] = true
6. // 判断长度为 2 的子串
7. for i = 1 to n-1:
8.     if A[i] == A[i+1]:
9.         dp[i][i+1] = true
10.        maxLen = 2
11. // 长度 >= 3
12. for len = 3 to n:
13.     for i = 1 to n - len + 1:
14.         j = i + len - 1
15.         if A[i] == A[j] and dp[i+1][j-1]:
16.             dp[i][j] = true
17.             maxLen = len
18. return maxLen
```

### 复杂度

- 时间复杂度：$O(n^2)$（填充 $n^2/2$ 个状态）
- 空间复杂度：$O(n^2)$（DP 表），可优化到 $O(n)$

## 10. 最小覆盖集的分支界限算法

### 问题定义

**顶点覆盖**：给定无向图 $G=(V,E)$，找最小的顶点子集 $C \subseteq V$，使得每条边至少有一个端点在 $C$ 中。

**NP 难度**：最小顶点覆盖问题是 NP 完全的（判定版本），因此对应的优化问题是 NP 难的。最小顶点覆盖问题可以通过 Karp 的 21 个 NP 完全问题列表得到证明。

### 分支限界算法

**上界**：使用贪心算法（每次选择度数最大的顶点加入覆盖集）得到一个可行解作为初始上界。

**下界（界函数）**：在剩余图中，选择边不相交匹配（即最大匹配的下界），每条匹配边至少需要一个顶点来覆盖，因此匹配大小是覆盖集大小的下界。

**分支策略**：选择一条边 $(u, v)$，分支：
- 分支 A：选择 $u$ 加入覆盖集（删除 $u$ 及其关联的所有边）
- 分支 B：选择 $v$ 加入覆盖集（删除 $v$ 及其关联的所有边）

**剪枝条件**：当前部分解大小 + 下界 $\geq$ 当前最优解（上界），则剪枝。

### 伪代码

```
best = |V|  // 初始上界 = 全部顶点

Function BBMinVertexCover(G, cover):
    if G 无边:
        if |cover| < best:
            best = |cover|
        return
    计算下界 lb  // 如最大匹配大小
    if |cover| + lb >= best:
        return  // 剪枝
    选择未覆盖的边 (u, v)
    // 分支1: 选 u
    BBMinVertexCover(G \ {u 及其关联边}, cover ∪ {u})
    // 分支2: 选 v
    BBMinVertexCover(G \ {v 及其关联边}, cover ∪ {v})
```

**使用回溯法（减 2 分）**：直接 DFS 枚举所有顶点子集并验证是否为顶点覆盖，时间复杂度为 $O(2^n \cdot m)$，其中 $m = |E|$。
