## 一、概念题

### (1) 元运算与基本运算

**元运算**：算法中不可再分解的基本计算步骤，是构成算法的最小操作单元。例如：一次加法、一次比较、一次赋值、一次数组索引访问。

**基本运算**：从元运算中选取的、能够反映算法核心计算量的那类操作。选取标准：该操作在算法中执行次数最多，且与问题规模有明确的渐近关系。

**举例**：
- **线性查找**：基本运算为元素比较（`A[i] == target`），执行次数为 $O(n)$。
- **冒泡排序**：基本运算为元素比较（`A[j] > A[j+1]`），执行次数为 $O(n^2)$。

### (2) 算法的空间复杂性

**算法使用空间的定义**：算法运行过程中所需的存储空间总量，等于**固定空间**（代码、常量、简单变量）与**可变空间**（输入数据大小相关的空间，如数组、递归栈等）之和。

**空间与时间的关系**：
- 一般来说，空间和时间可以互相转化（时空权衡）。
- 例如：动态规划增加空间存储中间结果来降低时间复杂度；而某些原地算法减少空间使用但可能增加时间。
- 二者并不总是正比关系——可通过牺牲时间来换取空间，反之亦然。

### (3) 确定性与不确定性算法

**确定性算法**：对于给定的输入，算法的每一步操作都是唯一确定的，不存在随机或非确定选择。运行多次，结果始终相同。例如：归并排序、Dijkstra 算法。

**不确定性算法**：算法中存在非确定性的选择步骤，不同执行可能产生不同结果。包括：
- **随机算法**（Las Vegas / Monte Carlo）：使用随机数做决策
- **非确定型图灵机模型**上的算法：理论上可在多项式时间内"猜测"正确解

**不确定多项式类型（NP）算法**：可以用非确定型图灵机在多项式时间内求解的问题。

## 二、负元素排在正元素之前

### 算法设计

**算法思想**：使用双指针（类似快速排序的划分），一个指针从左向右找正元素，另一个从右向左找负元素，遇到错位的就交换。

```
Algorithm ReorderNegPos(A[1..n])
Input: n 个实数组成的数组 A
Output: 重排后的数组, 所有负元素在正元素之前

1. i = 1, j = n
2. while i < j:
3.     while i < j and A[i] < 0:  // 找到左边第一个 >= 0 的数
4.         i = i + 1
5.     while i < j and A[j] >= 0:  // 找到右边第一个 < 0 的数
6.         j = j - 1
7.     if i < j:
8.         swap(A[i], A[j])
9.         i = i + 1
10.        j = j - 1
11. return A
```

### 时间复杂度

每个元素最多被访问一次，双指针相遇即结束，时间复杂度为 $O(n)$。

### 空间复杂度

仅使用两个指针变量，空间复杂度为 $O(1)$（原地算法）。

## 三、随机算法求 $\int_1^2 \frac{\sin x}{x} dx$

### 算法设计（蒙特卡洛积分法）

**算法思想**：使用均值法（Hit-or-Miss 或 Sample-Mean Monte Carlo）。

函数 $f(x) = \frac{\sin x}{x}$ 在 $x \in [1, 2]$ 上连续。可以通过随机采样来估计积分值。

**期望法**：在区间 $[1,2]$ 上取均匀分布的随机样本点，用样本均值估计积分：
$$\int_1^2 f(x)dx = (2-1) \cdot \mathbb{E}[f(X)] = \mathbb{E}[f(X)]$$

其中 $X \sim U(1,2)$。

```
Algorithm MonteCarloSinx(N)
Input: 采样次数 N
Output: 积分近似值

1. sum = 0
2. for i = 1 to N:
3.     x = 1 + random()  // random() 生成 [0,1], 转换到 [1,2]
4.     sum = sum + sin(x) / x
5. return sum / N
```

由于 $\int_1^2 \frac{\sin x}{x}dx \approx 0.659$，通过大数定律，当 $N \to \infty$ 时，近似值收敛于真实值。误差满足 $O(1/\sqrt{N})$（蒙特卡洛方法的收敛速度）。

## 四、矩阵路径最小和问题

### (1) 最优解表示与递推关系

**定义**：$dp[i][j]$ 表示从 $A_{11}$ 走到 $A_{ij}$ 的路径上经历元素之和的最小值。

**递推关系**：
$$dp[i][j] = A_{ij} + \begin{cases} dp[i-1][j] & \text{if } j=1 \\ dp[i][j-1] & \text{if } i=1 \\ \min(dp[i-1][j], dp[i][j-1]) & \text{otherwise} \end{cases}$$

边界条件：$dp[1][1] = A_{11}$。

### (2) 算法步骤

```
Algorithm MinPathSum(A[m][n])
Input: m×n 矩阵 A
Output: A[1][1] 到 A[m][n] 的最小路径和

1. 创建 dp[1..m][1..n]
2. dp[1][1] = A[1][1]
3. // 初始化第一行
4. for j = 2 to n:
5.     dp[1][j] = dp[1][j-1] + A[1][j]
6. // 初始化第一列
7. for i = 2 to m:
8.     dp[i][1] = dp[i-1][1] + A[i][1]
9. // 填充DP表
10. for i = 2 to m:
11.     for j = 2 to n:
12.         dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + A[i][j]
13. return dp[m][n]
```

### (3) 时间复杂度分析

算法需要填充一个 $m \times n$ 的 DP 表，每个单元格的计算为常数时间 $O(1)$。因此时间复杂度为 $O(m \times n)$，满足要求。

空间复杂度为 $O(m \times n)$（若只求最小值，可优化为 $O(n)$：只需保留上一行的值）。

## 五、石子合并问题

### (1) 递归方程

**定义**：$dp[i][j]$ 表示将第 $i$ 堆到第 $j$ 堆石子合并成一堆的最小得分。

**递归方程**：
$$dp[i][j] = \begin{cases} 0 & \text{if } i = j \\ \min_{i \leq k < j}\{dp[i][k] + dp[k+1][j]\} + \sum_{t=i}^{j} w_t & \text{if } i < j \end{cases}$$

其中 $w_t$ 是第 $t$ 堆石子的数量，$\sum_{t=i}^{j} w_t$ 表示合并区间 $[i,j]$ 内所有石子时本次合并的得分。

**能否直接用递归实现**：虽然表达式是递归的，但**不建议直接用简单递归实现**，因为存在大量重叠子问题，简单递归会导致指数级时间复杂度。应当使用备忘录（记忆化搜索）或自底向上的动态规划。

### (2) 伪代码

```
Algorithm StoneMerge(w[1..N])
Input: 石子堆数组 w
Output: 最小得分

1. 创建 dp[1..N][1..N], 初始化为 INF
2. 创建 sum[1..N]，sum[i] = w[1] + ... + w[i]  // 前缀和
3. for i = 1 to N:
4.     dp[i][i] = 0
5. for len = 2 to N:  // 区间长度
6.     for i = 1 to N - len + 1:
7.         j = i + len - 1
8.         total = sum[j] - sum[i-1]
9.         for k = i to j - 1:
10.            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j])
11.        dp[i][j] = dp[i][j] + total
12. return dp[1][N]
```

### (3) 时间复杂度

三重循环：区间长度 $O(N)$，起点 $O(N)$，分割点 $O(N)$。总时间复杂度为 $O(N^3)$。

### (4) 输出最优合并方案

在计算 $dp[i][j]$ 的同时，使用数组 `best[i][j]` 记录区间 $[i,j]$ 的最优分割点 $k$：

```
// 在 dp 更新处添加
if dp[i][k] + dp[k+1][j] < dp[i][j]:
    dp[i][j] = dp[i][k] + dp[k+1][j]
    best[i][j] = k  // 记录最优分割点

// 递归输出最优加括号方式
Function PrintMerge(i, j):
    if i == j:
        print w[i]
    else:
        print "("
        PrintMerge(i, best[i][j])
        PrintMerge(best[i][j]+1, j)
        print ")
```

空间复杂度：额外使用 `best[1..N][1..N]` 数组，空间复杂度为 $O(N^2)$。

## 六、回溯法输出全排列

### (1) 算法思想

使用回溯法（DFS）生成 $1$ 到 $N$ 的所有全排列：
- 用一个数组 `path` 记录当前排列
- 用一个数组 `used` 标记某个数字是否已被使用
- 从第一个位置开始，依次尝试将每个未使用的数字放入当前位置
- 当 `path` 长度达到 $N$ 时，输出当前排列
- 回溯：撤销选择，恢复 `used` 标记

### (2) $N=3$ 的解空间树

```
[]
              /         |         \\
            1           2          3
          /   \\       /   \\       /   \\
        12     13    21    23    31    32
        |      |     |     |     |     |
       123    132   213   231   312   321
```

### (3) 伪代码

```
Algorithm Permutations(N)
Input: 正整数 N
Output: 1..N 的所有全排列

1. path = []  // 当前排列
2. used[1..N] = {false}  // 标记数字是否已用
3. backtrack()

Function backtrack():
    if path.size() == N:
        输出 path
        return
    for x = 1 to N:
        if not used[x]:
            used[x] = true
            path.append(x)
            backtrack()
            path.pop()  // 撤销
            used[x] = false  // 撤销
```

**时间复杂度**：$O(N \cdot N!)$ —— 共 $N!$ 个排列，每个排列输出需 $O(N)$ 时间。

**空间复杂度**：递归栈深度为 $N$，加上 `used` 和 `path` 数组，总空间为 $O(N)$。
