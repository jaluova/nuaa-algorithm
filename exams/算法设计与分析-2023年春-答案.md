# 算法设计与分析 - 2023年春试卷 参考答案

## 一、

### (1) 用 $\Theta$ 表示 $f(n) = \log^3 n + n\log n + 2n^2$

分析各项的增长阶：
- $\log^3 n$ 的增长速度远慢于 $n$；
- $n\log n$ 的增长速度为 $\Theta(n\log n)$；
- $2n^2$ 的增长速度为 $\Theta(n^2)$。

由于 $n^2$ 是最高阶项，故 $f(n) = \Theta(n^2)$。

### (2) 算法的五个重要特性

1. **有穷性（Finiteness）**：算法必须在执行有限步后终止。
2. **确定性（Definiteness）**：每一条指令的含义必须明确，无二义性。
3. **可行性（Effectiveness）**：每一条指令都是可执行的（在有限时间内能用基本操作完成）。
4. **输入（Input）**：算法具有 0 个或多个输入。
5. **输出（Output）**：算法至少产生 1 个输出。

### (3) 子问题及其作用

**什么是子问题**：子问题是将原问题规模缩小后的同类问题。在分治、动态规划等算法设计方法中，我们将原问题分解为若干结构相同但规模更小的子问题。

**作用**：
- 降低问题复杂度：通过将大问题分解为小问题，使求解变得更容易；
- 利用子问题的解构造原问题的解；
- 实现递归/迭代求解（如动态规划中通过子问题最优解求得原问题最优解）；
- 利用子问题重叠性质避免重复计算（DP 的核心）。

### (4) 随机算法分析

该算法属于 **Las Vegas 算法** —— 总是返回正确结果（1 或 0，概率各 $1/2$），但运行时间是随机的。

**期望抛掷次数分析**：
每次循环连抛两次硬币。设每次循环中成功（即两次结果一正一反或一反一正）的概率为：
$$P(\text{success}) = P(\text{正反}) + P(\text{反正}) = p(1-p) + (1-p)p = 2p(1-p)$$

令 $q = 2p(1-p)$。每次循环成功的概率为 $q$，循环次数服从几何分布。
$$\mathbb{E}[\text{循环次数}] = \frac{1}{q} = \frac{1}{2p(1-p)}$$

每次循环抛 2 次硬币，故期望抛掷次数 = $2 \cdot \frac{1}{2p(1-p)} = \frac{1}{p(1-p)}$。

当 $p = 1/2$ 时（匀质硬币），$\mathbb{E} = 4$ 次。

### (5) 求解 $T(n) = 2T(n/2) + n - 1$，$T(1)=0$

这是标准的归并排序型递归式。

由主定理（Master Theorem）：$a=2$, $b=2$, $f(n)=n-1 = \Theta(n)$。
$\log_b a = \log_2 2 = 1$，$f(n) = \Theta(n^{\log_b a}) = \Theta(n)$，属于 Case 2。
$$T(n) = \Theta(n\log n)$$

精确解：设 $n=2^k$，迭代展开：
$$\begin{aligned} T(n) &= 2T(n/2) + n - 1 \\ &= 2[2T(n/4) + n/2 - 1] + n - 1 \\ &= 4T(n/4) + 2n - 3 \\ &= \cdots \\ &= nT(1) + n\log_2 n - (n-1) \\ &= n\log_2 n - n + 1 \end{aligned}$$

故 $T(n) = n\log_2 n - n + 1 = \Theta(n\log n)$。

### (6) 求 $T(n) = T(\lfloor n/3 \rfloor) + T(\lfloor 2n/3 \rfloor) + n$ 的渐近紧界

使用递归树法：每层总代价为 $n$，深度为 $O(\log_{3/2} n)$（因为每次减少至多 $2/3$ 规模）。

递归树最深链 $\approx \log_{3/2} n$（以 $3/2$ 为底，每层规模乘以 $2/3$）。每层代价为 $\Theta(n)$。

$$T(n) = \Theta(n\log n)$$

（与快速排序的期望时间复杂度分析类似）

## 二、找出缺失元素

### 算法思想

已知数组 $A[1..n-1]$ 已排序且包含了 $\{1, 2, \dots, n\}$ 中的 $n-1$ 个不同的数。可以利用**二分查找**来寻找缺失的元素：

对于下标 $i$，正常情况下 $A[i] = i$（如果从 1 到 $i$ 都在的话）。如果 $A[i] > i$，说明缺失的元素在前半部分；否则在后半部分。利用这个单调性质进行二分查找。

### 伪代码

```
Algorithm FindMissing(A[1..n-1])
Input: 已排序数组 A, 包含 {1,2,...,n} 中的 n-1 个不同数
Output: 缺失的元素 k

1. low = 1, high = n - 1
2. while low <= high:
3.     mid = (low + high) / 2
4.     if A[mid] == mid:  // 前半部分完整, 缺失在后半
5.         low = mid + 1
6.     else:  // A[mid] > mid, 缺失在前半
7.         high = mid - 1
8. return low  // low 即为缺失的元素
```

### 时间复杂度

二分查找，每次将搜索范围减半。时间复杂度为 $O(\log n)$，这是最优的——因为需要对 $n-1$ 个元素进行搜索，而线性扫描需 $O(n)$。

## 三、树的完美匹配

### 算法思想

使用贪心算法（自底向上）：对于一棵树，从叶子节点开始，每个叶子必须与其父节点匹配（否则叶子无法与其他节点匹配，因为树中叶子只有父节点这唯一邻居）。匹配后将该节点及其父节点从树中移除，递归处理。

### 算法描述

```
Algorithm TreePerfectMatching(T)
Input: 具有 2n 个顶点的树 T
Output: 完美匹配 或 "不存在"

1. 选择任意节点作为根, 进行 DFS 建立父子关系
2. matched[1..2n] = false
3. matching = []  // 存放匹配边
4. 对节点按 DFS 完成时间排序（后序遍历顺序, 即从叶子开始）
5. for each 节点 v in 后序遍历:
6.     if not matched[v]:
7.         if v 是根节点:
8.             return "不存在"
9.         u = parent[v]
10.        if matched[u]:
11.            return "不存在"
12.        matched[v] = true, matched[u] = true
13.        matching.append((v, u))
14. return matching
```

### 正确性证明

**引理**：在树的完美匹配中，每个叶子节点必须与其父节点匹配。

**证明**：叶子节点只有一个邻居（其父节点），因此必须与父节点匹配，否则无法匹配。

**算法正确性**：从叶子开始自底向上处理，每次处理未匹配的叶子 $v$ 时，其父节点 $u$ 必须未被匹配（否则 $v$ 无法匹配），此时将 $(v, u)$ 加入匹配是最优的：不存在其他方案，因为 $v$ 只能与 $u$ 匹配。

对每对匹配的节点 $(v, u)$，从树中移除它们后，递归处理剩余的子树。如果最终有节点未匹配，则不存在完美匹配。

时间复杂度：$O(n)$（一次 DFS 遍历即可）。

## 四、奶茶店选址问题

### 动态规划设计

**问题分析**：有 $n$ 个位置，若在第 $i$ 个开设，则后面 $f$ 个位置不能开。求最大总收益。

**状态定义**：$dp[i]$ 表示考虑位置 $1 \sim i$ 能获得的最大总收益。

**状态转移**：
- 不在第 $i$ 个位置开店：$dp[i] = dp[i-1]$
- 在第 $i$ 个位置开店：$dp[i] = p_i + dp[i - f - 1]$（前面不能开的位置跳过去）

$$dp[i] = \max(dp[i-1],\ p_i + dp[i - f - 1])$$

其中规定 $dp[k] = 0$（当 $k \leq 0$ 时）。

### 伪代码

```
Algorithm MaxTeaProfit(n, f, p[1..n])
Input: n 个位置, 间隔约束 f, 收益数组 p
Output: 最大总预期月收益

1. 创建 dp[0..n], 初始化为 0
2. for i = 1 to n:
3.     // 不选位置 i
4.     dp[i] = dp[i-1]
5.     // 选位置 i (需要跳过 f 个)
6.     prev = 0
7.     if i - f - 1 >= 1:
8.         prev = dp[i - f - 1]
9.     dp[i] = max(dp[i], p[i] + prev)
10. return dp[n]
```

### 复杂度分析

- **时间复杂度**：$O(n)$，一次线性遍历。
- **空间复杂度**：$O(n)$（dp 数组），可优化为 $O(f)$（只需保留最近 $f$ 个 dp 值）。

## 五、最大独立集问题

### (1) 判定版本与 NP 证明

**判定版本**：
- 输入：无向图 $G = (V, E)$，正整数 $k$
- 问题：是否存在一个独立集 $U \subseteq V$，满足 $|U| \geq k$？

**证明其属于 NP**：
给定一个"证书" $U \subseteq V$（候选独立集），可以在多项式时间内验证：
1. 检查 $|U| \geq k$（$O(|V|)$ 时间）
2. 检查 $\forall u, v \in U$，$(u, v) \notin E$（$O(|U|^2) \leq O(|V|^2)$ 时间）

因此，该判定问题属于 NP。

**NP 完全性**：最大独立集问题已被证明是 NP 完全的（通过从 3-SAT 归约，或通过与最大团问题、最小顶点覆盖问题的等价性）。

### (2) 分支限界算法

**核心思路**：

1. **上界函数（Bound）**：对当前部分解，估计在最好情况下能加入的最大顶点数。例如：
   - 贪心上界：当前独立集大小 + 剩余图中所有顶点的度数 0 的顶点数
   - 更紧的上界：当前大小 + 对剩余图进行图着色，用到的颜色数（因为独立集中任何两个顶点不能同色）

2. **分支策略**：选择一个顶点 $v$，分支为两种情况：
   - 分支 A：将 $v$ 选入独立集（删除 $v$ 及其所有邻居）
   - 分支 B：不选 $v$（删除 $v$）

3. **限界剪枝**：若 `当前独立集大小 + 上界 <= 当前已知最优解`，则剪枝。

4. **搜索顺序**：优先选择度数最大的顶点（能更快减少图规模）或启发式地优先选择更可能属于最大独立集的顶点。

```
算法: 最大独立集 - 分支限界
best = 0
bestSet = null

Function BBMaxIS(G, currentSet):
    if |currentSet| > best:
        best = |currentSet|
        bestSet = currentSet
    if G 为空图:
        return
    计算上界 bound
    if |currentSet| + bound <= best:
        return  // 剪枝
    选择分支顶点 v
    // 分支1: 选 v
    G1 = G 删除 v 及其邻居
    BBMaxIS(G1, currentSet ∪ {v})
    // 分支2: 不选 v
    G2 = G 删除 v
    BBMaxIS(G2, currentSet)
```

时间复杂度最坏为指数级（因为最大独立集问题是 NP 完全的），但分支限界可以大幅剪枝，在实际或特定图类上显著加速。
