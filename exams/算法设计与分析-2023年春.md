```
While(true)
    连抛两次硬币;
    if(两次结果分别为正面向上、反面向上) return 1;
    if(两次结果分别为反面向上、正面向上) return 0;
end While
```

该算法为哪一类的随机算法？分析该算法所抛硬币数目的期望值。

## 四、
