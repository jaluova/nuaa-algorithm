## 3着色问题

- NP完全问题
- 给定一个无向图 $G=(V,E)$，及3种颜色 $\{1,2,3\}$，现要为图的每个顶点着色。每顶点只能着一种颜色，并且要求相邻的顶点具有不同的颜色。
- 一个具有 $n$ 个顶点的图，可用一个 $n$ 维的向量 $(c_1,c_2,\dots,c_n)$ 表示一种着色方案，$c_i \in \{1,2,3\},\ i=1,2,\dots,n$，共有 $3^n$ 种可能的着色，可用一棵完全的3叉树表示。

![[img/回溯法-3着色问题-搜索树.png]]

```
for k <- 1 to n
	c[k] <- 0
end for

flag <- false
k <- 1
while k <= 1
	while c[k] <= 2
		c[k] <- c[k] + 1
		if c 是合法着色 then set flag <- true 且从两个 while 循环推出
		else if c 是部分解 then k <- k + 1
	end while
	c[k] <- 0
	k <- k - 1
end while

if flag then output c
else output "no solution"
```

## n皇后问题

- $n$皇后问题：当 $n=4$ 时 解的表示形式：$\{x_1,x_2,x_3,x_4\}$ 
- 互相攻击的情况： 
1. $x_i = x_j$ 
2. $x_i - x_j = i-j$ 或者 $x_i - x_j = j-i$

```
for k <- 1 to n
	c[k] <- 0
end for

flag <- false
k <- 1
while k <= 1
	while c[k] < n
		c[k] <- c[k] + 1
		if c 是合法解 then set flag <- true 且从两个 while 循环推出
		else if c 是部分解 then k <- k + 1
	end while
	c[k] <- 0
	k <- k - 1
end while

if flag then output c
else output "no solution"
```

## 一般回溯法

![[img/回溯法-一般算法框架-子步骤.png]]

- 回溯法适用于解决什么样的问题？
- 解的形式是**定长向量** 
- 用数组 $c[1,\dots,n]$ 的形式表示

- 假设 $c[k]$ 的取值范围是集合 $X_k$ 
- 特殊情况 $X_1=X_2=\dots=X_n=\{1,2,\dots,m\}$ 
- 两个基本的子步骤： - 判断 $c[1,\dots,n]$ 是否全合法 
- 判断 $c[1,\dots,k]$ 是否合法（部分合法，$k<n$）

```
while c[k] < m
	c[k] <- c[k] + 1
	if c 是合法解 then set flag <- true 且从两个 while 循环推出
	else if c 是部分解 then k <- k + 1
end while
```
