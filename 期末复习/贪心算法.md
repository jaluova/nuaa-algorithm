## 最短路径

```
X <- {1}; Y <- V - {1}
对每个 v 属于 Y，如果存在从 1 到 v 的边，则令 lambda[v]（v 的标记）为边的长度；否则令 lambda[v] = inf，并设 lambda[1] = 0
while Y != {}
	令 y 属于 Y，使得 lambda[y] 为最小
	将 y 从 Y 移到 X
	更新那些在 Y 中与 y 相邻的顶点的标记
end while
```

```
X <- {1}; Y <- V - {1}; lambda[1] <- 0

for y <- 2 to n
	if y 相邻于 1 then lambda[y] <- length[1,y]
	else lambda[y] <- inf
	end if
end for

for j <- 1 to n - 1
	令 y 属于 Y，使得 lambda[y] 为最小
	X <- X 并 {y}
	Y <- Y - {y}
	for 每条边(y,w)
		if w 属于 Y and lambda[y] + length[y,w] < lambda[w] then
			lambda[w] <- lambda[y] + length[y,w]
		end if
	end for 
end for
```

### 贪心选择性质

Dijkstra 算法在每一步选择当前标记最小的未被访问顶点，这个局部最优选择最终导向全局最优解。

**证明思路（归纳法）**：设前 $k$ 步选出的顶点集合 $X$ 中，所有顶点的标记等于从源点到该顶点的最短距离。归纳步：第 $k+1$ 步选出的 $y$ 也满足此性质。

### 时间复杂度

$O(n^2+m)$，若使用优先队列（堆）优化可达 $O((n+m)\log n)$


## 不相交集数据结构（并查集）

**MAKESET** 的时间复杂度 $O(n)$
每次 **FIND** 和 **UNION** 的时间复杂度 $O(\log n)$

## 最小生成树

### Kruskal

```
按非降序权重将 E 中边排序
for 每条边 v 属于 V
	MAKESET({v})
end for

T = {}
while |T| < n - 1
	令 (x, y) 为 E 中的下一条边
	if FIND(x) != FIND(y) then
		UNION(x,y)
	end if
end while
```

- 时间复杂度：$O(m\log m)$（排序主导）

### Prim

```
T <- {}; X <- {1}; Y <- V - {1}
while Y != {}
	设 (x,y) 是最小权重的边，其中 x 属于 X，y 属于 Y
	X <- X 并 {y}
	Y <- Y - {y}
	T <- T 并 {(x,y)}
end while
```

```
T <- {}; X <- {1}; Y <- V - {1}
for y <- 2 to n
	if y 领接于 1 then
		N[y] <- 1
		C[y] <- c[1,y]
	else C[y] <- inf
	end if
end for

for j <- 1 to n - 1
	令 y 属于 Y，使得 C[y] 最小
	T <- T 并 {(y,N[y])}
	X <- X 并 {y}
	Y <- Y - {y}
	for 每个邻接于 y 的顶点 w 属于 Y
		if c[y,w] < C[w] then
			N[w] <- y
			C[w] <- c[y,w]
		end if
	end for
end for
```

```
T <- {}
X <- {1}
Y <- V - {1}
for v <- 2 to n
	if v 邻接于 1
		C[v] <- c[1,v]
		N[v] <- 1
	end if
end for


for j <- 1 to n - 1
	从 Y 中选取 v 使得 C[v] 最小
	T <- T + {(v,N[v])}
	X <- X + {v}
	Y <- Y - {v}
	for 每个邻接于 v 的节点 w in Y
		if c[v,w] < C[w]
			C[w] <- c[v,w]
			N[w] <- v
		end if
	end for 
end for
```

时间复杂度：$O(n^2)$，若用堆优化为 $O(m\log n)$

### Kruskal vs Prim 对比

| 算法 | 核心思想 | 适合的图 |
|---|---|---|
| Kruskal | 按边权排序，贪心选最小边（不构成环） | 稀疏图 |
| Prim | 从顶点出发，每次选连接已选/未选集合的最小边 | 稠密图 |
