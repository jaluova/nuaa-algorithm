## 基本概念

如果$T$是有$n$个顶点的树，那么
1. $T$中任意两个顶点有唯一的一条路径连通
2. $T$恰有$n-1$条边
3. 在$T$中加一条边将构成一个回路

**满二叉树**：每个内部节点都正好有两个儿子
**完全二叉树**：是满二叉树，且所有叶子有同样的深度

## 完全二叉树的性质

- 完全二叉树，第$x$层，左起第$y$个，编号是$2^x+y-1$。
- 叶子节点的个数是$\lfloor n / 2 \rfloor$，非叶子节点个数$\lceil n / 2 \rceil$。
- 节点个数总是奇数

几乎完全二叉树的层数是$\lfloor \log n \rfloor$

## 二叉树的高度

- $n$ 个节点的二叉树，高度最小为 $\lfloor \log n \rfloor$（完全二叉树），最大为 $n$（退化成链表）
- 堆是一棵**几乎完全二叉树**，高度为 $\lfloor \log n \rfloor$，因此 Sift-up / Sift-down 的复杂度为 $O(\log n)$

## 与堆的关系

堆是二叉树的数组实现，详见 [[堆]]。大顶堆满足：任何节点的值 $\ge$ 其子节点的值。
