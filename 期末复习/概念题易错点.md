## 分治法三步骤

| 步骤 | 名称 | 含义 |
|------|------|------|
| 1 | **分（Divide）** | 将原问题分解为规模更小的**同类**子问题 |
| 2 | **治（Conquer）** | **递归**求解各子问题（到阈值 $n_0$ 直接解） |
| 3 | **合（Combine）** | 将子问题的解合并为原问题的解 |

注意：并非所有分治算法都需要"合"（如二分查找）。

---

## 动态规划 — 两个性质 vs 三个步骤

### 两个基本性质（DP 成立的前提）

1. **最优子结构**：问题的最优解包含其子问题的最优解
2. **重叠子问题**：递归过程中反复遇到相同的子问题

> "自底向上"不是性质，是实现方式！

### DP 设计三步骤

1. 分析最优解决方案应该具备的结构 → 验证**最优子结构**
2. 递归定义最优解 → 利用**重叠子问题**
3. **自底向上**构建 → 填表/迭代

### DP vs 分治法的核心区别

- 分治法：子问题**互不相交**，各自独立求解
- DP：子问题**大量重叠**，用表格存储避免重复计算（以空间换时间）

## 渐进符号 — 极限判定法

$$\lim_{n \to \infty}\frac{f(n)}{g(n)} = \begin{cases} 0 & \Rightarrow f = O(g),\; f \neq \Omega \\ \text{常数 } c > 0 & \Rightarrow f = \Theta(g) \text{（三个都真）} \\ \infty & \Rightarrow f = \Omega(g),\; f \neq O \end{cases}$$

常见复杂度排序：$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$

关键结论：
- $(\log n)^k$ 比任何 $n^\epsilon$（$\epsilon > 0$）增长慢
- $a^n$（$a>1$）比任何 $n^k$ 增长快
- $n!$ 比任何 $a^n$ 增长快

## 贪心算法 — 两个性质

1. **贪心选择性质**：每一步做当前最优选择
2. **最优子结构**

与 DP 的区别：贪心只看当前一步，不回溯；DP 考虑所有子问题取最优。

## 随机算法 — 两类对比

| | 蒙特卡罗 | 拉斯维加斯 |
|---|---|---|
| 结果正确性 | **可能出错** | **一定正确** |
| 是否总能找到解 | 总能返回结果 | 可能找不到解 |
| 典型应用 | 素性测试 | N皇后、快排随机选主元 |

## 回溯法

- 适用条件：**解必须是定长向量**（不同可行解不能有长有短）
- 对可行解树进行搜索
- 时间开销与搜索深度有关

---

## NP 完全问题

- **P 类**：多项式时间可解
- **NP 类**：多项式时间可验证
- **NP 完全**：属于 NP，且所有 NP 问题可规约到此问题
- **规约（Reduction）**：将问题 A 转化为问题 B，A 不超过 B 难
