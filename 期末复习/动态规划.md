## 最长公共子序列

- $A=<A_1A_2...A_n>,B=<B_1B_2...B_n>$
- 定义$L[i,j]$表示$<A_1A_2...A_n>$和$<B_1B_2...B_n>$的最长公共子序列的长度
- $L[i,0]=L[0,j]=0$
- 目标：求$L[n,m]$

- 如果$A_i=B_j$，$L[i,j]=L[i-1,j-1]+1$
- 如果$A_i\ne B_j$，$L[i,j]=max\{L[i-1,j],L[i,j-1]\}$

```
for i <- 0 to n
	L[i,0] <- 0
end for
for j <- 0 to n
	L[0,j] <- 0
end for
```

```
for i <- 1 to n
	for j <- 1 to n
		if A[i] = B[j] then
			L[i,j] = L[i-1,j-1] + 1
		else
			L[i,j] = max(L[i-1,j], L[i,j-1])
		end if
	end for	
end for
return L[n,m]
```

### 回溯构造

 从 $L[m,n]$ 开始，重复执行以下步骤： 
 1. 若 $A[j] == B[i]$：将该字符加入结果，执行 $i--,\ j--$ 
 2. 否则，若 $L[i-1,j] > L[i,j-1]$：执行 $i--$ 
 3. 否则：执行 $j--$

### 压缩到一维数组存储

计算 $L[i,j]$ 时仅依赖上一行和当前行的左侧值，故可用两个一维数组（或一个滚动数组）将空间从 $O(nm)$ 降至 $O(\min(n,m))$。

## 矩阵链相乘

- 求出计算$n$个矩阵相乘$M_1M_2...M_n$所需的最少的乘法次数

- 如果$M_1M_2$分别是$a\times b$和$b\times c$，那么计算$M_1M_2$需要的乘法为$a \times b \times c$次
![[img/矩阵链相乘-维度示意图.png]]

- 第一种计算顺序，$M_1M_2M_3=(M_1M_2)M_3$，需要200+200=400
- 第二种计算顺序，$M_1M_2M_3=M_1(M_2M_3)$，需要40+40=80

假设$n$个矩阵相乘可能的结合顺序有$f(n)$种，则
$$\underbrace{\left(M_1M_2\cdots M_k\right)}_{f(k)} \times \underbrace{\left(M_{k+1}M_{k+2}\cdots M_n\right)}_{f(n-k)}$$
$$f(k)*f(n-k),\ \text{其中}\ k=1,2,\dots,n-1$$ $$f(n)=\sum_{k=1}^{n-1}f(k)f(n-k)$$
$$f(n)=\frac{1}{n}\binom{2n-2}{n-1},f(n)=\Omega\left(\frac{4^n}{n^{1.5}}\right)$$
- 动态规划：
- 数组$r[1,2,\dots,n+1]$中存储每个矩阵的行数和列数
- 设置$r[i]$存储矩阵$M_i$的行数，则 $i>1$时，$r[i]$必然也是矩阵$M_{i-1}$的列数
- 设置$r[n+1]$存储矩阵$M_n$的列数

记 $M_{i,j}=M_iM_{i+1}\cdots M_j$， $C[i,j]$ 是计算 $M_{i,j}$ 所需要的数量乘法的最少次数 $$ \underbrace{\left[M_iM_{i+1}\cdots M_{k-1}\right]}_{C[i,k-1]} \underbrace{\left[M_kM_{k+1}\cdots M_j\right]}_{C[k,j]} \quad \text{其中 }k=i+1,\dots,j $$ $$ \underbrace{r[i]*r[k]*r[j+1]}_{\text{合并代价}} $$ $$ C[i,j]=\min_{i<k\le j}\big\{C[i,k-1]+C[k,j]+r[i]\cdot r[k]\cdot r[j+1]\big\} $$
目标转化为求$C[1,n]$，且$C[i,i]=0$。

```
for i <- 1 to n
	C[i,i] <- 0
end for

for d <- 1 to n - 1
	for i <- 1 to n - d
		j <- i + d
		// 下列三行计算 C[i,j]
		C[i,j] <- inf
		for k <- i + 1 to j
			C[i,j] <- min(C[i,j], C[i,k-1]+C[k,j]+r[i]r[k]r[j+1])
		end for
	end for
end for
```

## 所有点的最短路径

- 问题：$G=(V,E)$ 有向带权图 $l[i,j]$ 为 $i$ 到 $j$ 的边的权值，若无边则为 $+\infty$ 
- $V$ 包含 $n$ 个顶点，记为 $\{1,2,\dots,n\}$ 
- 求出任意两个顶点之间的最短路径长度 
- 最终结果存储：$n\times n$ 的二维数组 如 $D[1,2,\dots,n][1,2,\dots,n]$，其中 $D[i][j]$ 表示 $i$ 到 $j$ 的最短路径长度 $$ D_0[i][j]=l[i,j],\quad D_n[1,2,\dots,n][1,2,\dots,n] $$

- Floyd算法
- $D_k[1,2,\dots,n][1,2,\dots,n]$ 的含义 $$D_k[i][j]=d_{i,j}^k$$ $d_{i,j}^k$ 是从 $i$ 到 $j$，并且不经过 $\{k+1,k+2,\dots,n\}$ 中任何顶点的最短路径的长度。

- 计算$d_{i,j}^k$有两种可能
	1. 不经过$k$
	2. 经过$k$

```
D <- l
for k <- 1 to n
	for i <- 1 to n
		for j <- 1 to n
			D[i][j] <- min(D[i][j], D[i][k] + D[k][j])
		end for
	end for
end for
```

## 背包问题

- 物品集 $U=\{u_1,u_2,\dots,u_n\}$，背包容量为 $C$ 
- $s_i$ 和 $v_i$ 分别为 $u_i$ 的体积和价值
- 求出 $U$ 的子集 $S$，使得 $\sum_{u_i\in S} v_i$ 最大且 $\sum_{u_i\in S} s_i \le C$

- 定义 $V[i,j]$ 表示从前 $i$ 个物品 $\{u_1,u_2,\dots,u_i\}$，背包体积为 $j$ 时，能够获得的最大价值。 
- 那么，若 $i=0$ 或 $j=0$， $V[i,j]=0$ 
- 目标是计算 $\boldsymbol{V[n,C]}$

- 若 $i=0$ 或 $j=0$， $V[i,j]=0$ 
- 若$j<s_i$，$V[i,j]=V[i-1,j]$
- 若$i>0$且$j>=s_i$
	- 不装$u_i$
	- 装$u_i$
	- $V[i,j]=max\{V[i-1,j],V[i-1,j-s_i]+v_i\}$

![[img/背包问题-01背包-状态转移方程.png]]

```
for i <- 0 to n
	V[i,0] <- 0
end for

for j <- 0 to n
	V[0,j] <- 0
end for

for i <- 1 to n
	for j <- 1 to n
		V[i, j] <- V[i-1,j]
		if s_i <= j then V[i,j] <- max{V[i,j], V[i-1,j-s_i]+v_i}
	end for
end for
```
