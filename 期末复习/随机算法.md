## 算法特点

- 优点
	- 期望性能优良、适用于大规模数据集
	- 简化算法设计，并降低算法运行开销
	- 避免最坏情况
- 缺点
	- 结果具有不确定性，可能错，可能近似
	- 只是期望性能优，实际执行也可能差
	- 需要高质量随机数，理论分析复杂

## 蒙特卡罗算法

**总是返回一个答案，但可能是错的**

- 例子：寻找较大数

```
输入：A[1,...,n], k
输出：数组中较大的 n / 2 个数中的任一个数 x

x <- -inf
for i <- 1 to k
	y <- A[random(1, n)]
	if y > x then x <- y
end for
return x
```

正确的概率：$p=1-0.5^k$

### 素性测试（Fermat）

```
算法：FermatPrimalityTest(n, k)
输入：整数 n > 2，测试次数 k（安全参数）
输出：若返回 COMPOSITE，则 n 一定是合数；若返回 PRIME，则 n 可能是素数

if n 是偶数 then
	if n = 2 then return PRIME
	else return COMPOSITE
end if   

for i <- 1 to k
    a = random(2, n - 2)
    if gcd(a, n) != 1 then
        return COMPOSITE                 // 找到了非平凡因子
    else if then a^{n-1} mod n != 1：    // 使用模重复平方算法计算
	    return COMPOSITE                 // 费马测试失败，n 必为合数
	end if
end for
return PRIME                             // 通过 k 轮测试，n 很可能是素数
```

## 拉斯维加斯算法

**可能无法返回一个答案，但只要返回答案，肯定是对的**

- 例子

```
输入：A[1,...,n]，含有 n / 2 + 1 个相同值 x，另外的元素互异且不等于 x
输出：x

for i <- 1 to k
	if i != j and A[i] != A[j] then
		return A[i]
	end if
end for

return NULL
```


## 蒙特卡罗 vs 拉斯维加斯

| 类型 | 返回答案 | 答案正确性 | 典型应用 |
|---|---|---|---|
| 蒙特卡罗 | 一定返回 | 可能错 | 素性测试 |
| 拉斯维加斯 | 可能不返回 (NULL) | 一定对 | N皇后随机+回溯 |

## 应用场景

- 随机化快速排序：随机选 pivot
- 随机化第 $k$ 小元素：随机选候选值取代 5 个一组，期望时间复杂度仍为 $O(n)$，且常数系数更小
- $n$ 皇后问题：先随机放置前几个皇后，再用回溯法处理剩余行 → 降低搜索深度
- 图着色问题：类似思路

## 快排最坏情况

原数组已有序时，每次划分一侧为 0 → 时间复杂度 $O(n^2)$。**随机选主元可避免。**
