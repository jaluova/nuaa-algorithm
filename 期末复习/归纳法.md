## 插入排序

- 排序$A[1,...,n]$
- 如果能对$A[1,...,i]$进行排序，那么就能对$A[1,...,i+1]$进行排序
- `sort(A, 1, i)`，$i>1$，实现对$A[1,...,i]$排序

```
if i > 1 then
	sort(A, 1, i - 1)
	把 A[i] 插入到有序序列
end if
```

```
x <- A[i]
j <- i - 1
while j > 0 and A[j] > x
	A[j + 1] <- A[j]
	j <- j - 1
end while
A[j + 1] <- x
```

时间复杂度：
- 元素赋值次数记为$C(n)$
- $C(n)=C(n-1)+(n-1)$

$$
\begin{aligned}
C(n)=C(n-1)+(n-1) \\ 
C(n-1)=C(n-2)+(n-2) \\
C(n)=C(n-2)+(n-2)+(n-1) \\
C(n)=C(1)+1+2+...+(n-1) \\
C(n)=O(n^2)
\end{aligned}
$$

## 寻找多数元素

- 多数元素：出现次数大于$n / 2$的元素
- 先排序，再判断
- 找出可能是多数元素的值
- 判断这个可能值是否是多数元素

```
count <- 0
for j <- 1 to n
	if A[j] = c then count <- count + 1
end for
if count > floor(n / 2) then return c
else return none
```

- 怎么找候选者？
- 找出$A[m,...,n]$可能是多数元素的值
	- 如果$A[m] \ne A[m+1]$，则可以排除它俩，从$A[m+2,...,n]$中寻找
	- 如果$A[m] = A[m+1]$，继续考察$A[m+2]、A[m+3]、...$

步骤可以改造为：
- $count$初始值设为1
- 如果$A[j] = A[m]$，则$count++$，否则$count--$
- 当$count$减到$0$的时候，说明删掉了若干两两不等的元素对(有点意思的表述)，则可以从$A[j+1,...,n]$中开始寻找候选值

```
c <- candidata(1)
for j <- 1 to n
	if A[j] = c then count <- count + 1
end for
if count > floor(n / 2) then return c
else return none
```

```
candidate(m)

j <- m; c <- A[m]; count <- 1
while j < n and count > 0
	j <- j + 1
	if A[j] = A[m] then count <- count + 1
	else count <- count - 1
end while
if j = n then return c
else return candidate(j + 1)
```

非递归版本：

```
while m <= n
	j <- m; c <- A[m]; count <- 1
	while j < n and count > 0
		j <- j + 1

		else count <- count - 1

```

## 整数幂

- 计算$x$（实数）的$n$次幂， $x^n=?$
- 如果能计算出$x$的$b$次幂，$b=\left\lfloor \frac{n}{2} \right\rfloor$
- 那么就可以计算出$x$的$n$次幂

$t=x^b,y=t^2（n为偶）,y=x*t^2（n为奇）$

```
power(x, m)

if m = 0 then y <- 1
else
	y <- power(x, floor(m / 2))
	y <- y ** 2
	if m 为奇数 then y <- xy
end if
return y
```

计算代价满足$C(n) \le C(n/2) + 2$，时间复杂度为$O(logn)$

$$
\begin{aligned}
C(n) \le C(n/2) + 2 \\
C(n/2) \le C(n/4) + 2 \\
C(n/4) \le C(n/8) + 2 \\
C(n) \le C(n/4) + 4 \\
C(n) \le C(n/8) + 6 \\
C(n) \le C(n/2^k) + 2k \\
n = 2^k,k=\log n \\
C(n) \le C(1) + 2k
\end{aligned}
$$

### 矩阵/斐波那契数列

斐波那契数列满足如下条件： $$ \begin{cases} F_0=0,\ F_1=1,\\ \text{当}n\ge2\text{时},\ F_n=F_{n-1}+F_{n-2} \end{cases} $$ 假设矩阵 $A=\begin{bmatrix}1&1\\1&0\end{bmatrix}$，那么 $$ \begin{bmatrix}F_n\\F_{n-1}\end{bmatrix}=A\begin{bmatrix}F_{n-1}\\F_{n-2}\end{bmatrix}=A^2\begin{bmatrix}F_{n-2}\\F_{n-3}\end{bmatrix}=\dots=A^{n-1}\begin{bmatrix}F_1\\F_0\end{bmatrix} $$ 即 $F_n$ 等于 $A^{n-1}$ 左上角的元素值。 令 $m=n^3$，利用以上结论，能在 $\Theta(\log n)$ 时间求出斐波那契数列中的 $F_m$ 吗？如果能，给出相应的算法；如果不能，说明理由。


## 多项式求值

$$P_n(x) \equiv a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$$ 对于任意$i$，那么 $a_ix^i = a_i \cdot \underbrace{x \cdot x \cdot \dots \cdot x}_{i\text{次}}$

```
p <- a_n
for j <- 1 to n
	p <- x * p + a_{n - j}
end for
return p
```

```
y <- 1; p <- a_0
for j <- 1 to n
	y <- y * x
	p <- p + y * a_j
end for
return p
```

## 有序数组中查找两数之和为 x

已知数组**有序**，给出三种时间复杂度的算法：

| 复杂度 | 思路 | 说明 |
|---|---|---|
| $O(n^2)$ | 双重循环枚举所有对 $(i,j)$ | 对每个 $A[i]$，遍历后面所有 $A[j]$，检查 $A[i]+A[j]=x$ |
| $O(n\log n)$ | 枚举 + 二分搜索 | 对每个 $A[i]$，在剩余部分二分查找 $x-A[i]$ |
| $O(n)$ | 双指针 | `low=1, high=n`；若 $A[low]+A[high]<x$ 则 `low++`，若大于则 `high--`，相等则找到 |

> 双指针正确性：每次比较后，可以安全地排除一个方向——若和太小，$A[low]$ 不可能是任何解的左端（因为右端已经最大）；若和太大，$A[high]$ 不可能是任何解的右端。
