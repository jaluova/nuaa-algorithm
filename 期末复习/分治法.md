比较次数： $$ C(n)= \begin{cases} 1, & n=2 \\ 2C(n/2)+2, & n>2 \end{cases} $$ $$ \begin{align*} C(n) &= 2C(n/2) + 2 \\ &= 2(2C(n/4)+2)+2 \\ &= 4C(n/4)+4+2 \\ &= 4(2C(n/8)+2)+4+2 \\ &= 8C(n/8)+8+4+2 \\ &\vdots \\ &= 2^{k-1}C(2)+\sum_{j=1}^{k-1}2^j \\ &= (n/2)+2^k-2 \\ &= \frac{3n}{2}-2 \end{align*} $$
## 二分搜索

```
binarysearch(low, high)

if low > high then return 0
else 
	mid <- floor((low + high) / 2)
	if x = A[mid] then return mid
	else if x < A[mid] then return binarysearch(low, mid - 1)
	else return binarysearch(mid + 1, high)
end if
```

复杂度(最坏)：令$n=high-low+1$， $C(n)$表示最坏情况下的比较次数，那么 $$ C(n)\leqslant \begin{cases} 1 & \text{若 } n=1 \\ 1+C\left(\left\lfloor \frac{n}{2} \right\rfloor\right) & \text{若 } n\geqslant2 \end{cases} $$ 不妨设$2^{k-1}\leqslant n<2^k$，则 $$ \begin{align*} C(n)&\leqslant 1+C\left(\left\lfloor \frac{n}{2} \right\rfloor\right) \\ &\leqslant 2+C\left(\left\lfloor \frac{n}{4} \right\rfloor\right) \\ &\vdots \\ &\leqslant (k-1)+C\left(\left\lfloor \frac{n}{2^{k-1}} \right\rfloor\right) \\ &= (k-1)+1 \\ &= k \end{align*} $$ 所以，$\boldsymbol{C(n)=O(\log n)}$

## 分治范式


- 分治算法的好处：
- 递归算法和迭代算法的转换
- 主要思路：
	- 划分步骤：分成$p \ge 1$部分
	- 治理步骤：递归过程$\rightarrow$阈值$n_0$
	- 组合步骤：将$p$个部分解，组合成原始问题的解


1. 如果问题$I$的规模很小，直接求解，否则做下一步； 
2. 把问题$I$划分为$p$个子问题$I_1,\ I_2,\ \dots,\ I_p$； 
3. 对每个子问题，递归调用算法，得到子问题的解；
4. 组合$p$个子问题的解，返回$I$的解

## 寻找第k小元素

### 充要条件

对任意$x \in \boldsymbol{A}$，定义三个集合 $$ \begin{align} A_1&=\{a\mid a<x\}, \\ \quad A_2&=\{a\mid a=x\}, \\ A_3&=\{a\mid a>x\} \end{align} $$ 那么，$x$为第$k$小元素**当且仅当** $$\boldsymbol{|A_1|<k \quad 且 \quad |A_1|+|A_2|\geqslant k}$$
### 解决思路：

![[img/BFPRT-选择算法-第k小元素-示例1.png]]

![[img/BFPRT-选择算法-第k小元素-示例2.png]]

$$ \begin{align*} 
&\text{select}(A, low, high, k): \\ 
&1.\quad p \leftarrow high - low + 1 \\ 
&2.\quad \text{if } p < 44 \ \text{then} \\ &\quad\quad \text{将 } A \text{ 排序, return } A[k] \\ 
&3.\quad q \leftarrow \lfloor p/5 \rfloor, \text{ 将 } A \text{ 分为 } q \text{ 组, 每组 } 5 \text{ 个元素} \\ 
&4.\quad \text{对每组排序, 取中位数, 构成集合 } M \\ 
&5.\quad mm \leftarrow \text{select}(M, 1, q, \lfloor q/2 \rfloor) \\ &6.\quad \text{将 } A[low\cdots high] \text{ 分为} \\ &\quad\quad A_1 = \{a \mid a < mm\},\ A_2 = \{a \mid a = mm\},\ A_3 = \{a \mid a > mm\} \\ &7.\quad \text{if } |A_1| \ge k \ \text{then return } \text{select}(A_1, 1, |A_1|, k) \\ 
&8.\quad \text{else if } |A_1| + |A_2| \ge k \ \text{then return } mm \\ &9.\quad \text{else return } \text{select}(A_3, 1, |A_3|, k - |A_1| - |A_2|) \end{align*} $$

## 快速排序

```
SPLIT(A, low, high)

i <- low
x <- A[low]
for j <- low + 1 to high
	if A[j] <= x then
		i <- i + 1
		if i != j then swap(A[i], A[j])
	end if 
end for
swap(A[low], A[i])
w <- i
return A 和 w
```


$$ \begin{align*} &C(1) = 0; \\ &n>1\text{时},\quad C(n) = (n-1)+C(X_{\text{左}})+C(n-1-X_{\text{左}}) \end{align*} $$
### 平均情况

假设每次划分后，基准 $x$ 落在任意位置的概率相等，则：
$$C(n) = (n-1) + \frac{1}{n}\sum_{w=1}^{n}\big(C(w-1)+C(n-w)\big)$$
化简得 $C(n) \approx 2n\ln n \approx 1.39n\log_2 n$，平均时间复杂度 $\Theta(n\log n)$。

### 最坏情况

当数组已有序（或逆序），每次划分一侧为 0、另一侧为 $n-1$：
$$C(n) = (n-1) + C(n-1) = \frac{n(n-1)}{2} = \Theta(n^2)$$

随机化选主元可将最坏情况的发生概率降至极低。


## 大整数乘法

- 不定长的大整数相乘
- 优化前
$$ \begin{align*} u &= w2^{n/2}+x \\ v &= y2^{n/2}+z \end{align*} $$
$$ \begin{align*} u * v &= \big(w2^{n/2}+x\big)\big(y2^{n/2}+z\big) \\ &= wy2^{n}+(wz+xy)2^{n/2}+xz \end{align*} $$
$$ T(n)= \begin{cases} d & \text{若 } n=1 \\ 4T\left(\dfrac{n}{2}\right)+bn & \text{若 } n>1 \end{cases} $$ $$T(n)=\Theta(n^2)$$
- 优化后（Karatsuba）

![[img/大整数乘法-Karatsuba公式推导.png]]

$$wz+xy=(w+x)(y+z)-wy-xz$$
$$ T(n)= \begin{cases} d & \text{若 } n=1 \\ 3T\left(\dfrac{n}{2}\right)+bn & \text{若 } n>1 \end{cases} $$ $$T(n)=\Theta(n^{\log_2 3})=\Theta(n^{1.59})$$
