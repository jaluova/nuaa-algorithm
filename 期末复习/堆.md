总回顾：[[知识点范围]]

- 插入元素$O(\log n)$
- 寻找最大（最小）元素$O(1)$

## 定义

- 条件1：堆是几乎完全二叉树
- 条件2:堆中任何节点$v$，$v$的父节点中元素值**不小于**$v$的元素值（大顶堆）


- 根节点$H[1]$
- 左孩子$H[2j]$，右孩子$H[2j+1]$
- 如果$j>1$，$H[j]$的父节点是$H\left[\left\lfloor \frac{j}{2} \right\rfloor\right]$
- 高度是$\lfloor \log n \rfloor$

## 判断一个堆

```
for i <- n/2 downto 1
	j <- 2i
	if j + 1 <= n and H[j + 1] > H[j] then j <- j + 1
	if H[i] < H[j] return 0
end for	

return 1
```

## 堆上基本操作

- $\boldsymbol{\text{make-heap}(A)}$: 从数组$A$创建堆
- $\boldsymbol{\text{insert}(H, x)}$: 插入元素$x$到堆$H$中 
- $\boldsymbol{\text{delete}(H, i)}$: 删除堆$H$的第$i$项$H[i]$ 
- $\boldsymbol{\text{delete-max}(H)}$: 从非空堆$H$中删除最大键值并返回数据项

两者的适用条件是：除了$H[i]$，都满足堆的要求
### Sift-up

若某个节点$H[i]$键值大于其父节点的键值，就违背了堆的特性，需要进行调整。

```
inpu：H i
output：上移 H[i]

done <- false
if i = 1 then exit
repeat
	if key(H[i]) > key(H[i/2]) then swap(H[i], H[i/2])
	else done <- true
	i <- i / 2
until i = 1 or done
```

时间复杂度$O(\log n)$，空间复杂度$O(1)$

### Sift-down

```
done <- false
if 2i > n then exit
repeat
	i <- 2i
	if i + 1 <= n and key(H[i + 1]) > key(H[i]) then i <- i + 1
	if key(H[i/2]) < key(H[i]) then swap(H[i], H[i/2])
	else done <- true
	end if
until 2i > n or done
```

时间复杂度$O(\log n)$，空间复杂度$O(1)$

### INSERT

```
n <- n + 1
H[n] <- x
SIFT-UP(H, n)
```

### DELETE

非空堆 $H[1\cdots n]$ 和位于 $1$ 和 $n$ 之间的索引 $i$。

```
x <- H[i]; y <- H[n]
n <- n - 1
if i = n + 1 then exit
H[i] <- y

if key(y) >= key(x) then SIFT-UP(H, i)
else SIFT-DOWN(H, i)
end if
```

### DELETEMAX

返回最大元素并从堆中删除

```
x <- H[1]
DELETE(H, 1)
return x
```

### MAKEHEAP

```
for i <- n/2 downto 1
	SIFTDOWN(A, i)
end for
```

时间复杂度$O(n)$


设树高为 H ≈ log n。

第 h 层有最多 **n / 2^{h+1}** 个节点，每个最多下沉 **h** 步：

$$
\sum_{h=0}^{H} \frac{n}{2^{h+1}} \cdot h
= n \sum_{h=0}^{H} \frac{h}{2^{h+1}}
< n \sum_{h=0}^{\infty} \frac{h}{2^{h+1}}
= n \cdot 1
= O(n)
$$

关键就在那个级数收敛到 1。一半节点沉 0 次，剩下的加起来也没多少。
