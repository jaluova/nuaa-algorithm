## 二、矩阵链乘法问题

### 2.1 问题背景

给定 $n$ 个矩阵 $M_1 \times M_2 \times \cdots \times M_n$，每个矩阵 $M_i$ 的维度为 $r_{i-1} \times r_i$。

矩阵乘法满足结合律，不同的加括号方式虽然结果相同，但**标量乘法次数**可能相差巨大。

### 2.2 例子

$M_1: 10 \times 2,\; M_2: 2 \times 10,\; M_3: 10 \times 2$

- 顺序 $(M_1 M_2) M_3$：$(10 \times 2 \times 10) + (10 \times 10 \times 2) = 200 + 200 = 400$ 次
- 顺序 $M_1 (M_2 M_3)$：$(2 \times 10 \times 2) + (10 \times 2 \times 2) = 40 + 40 = 80$ 次

相差 **5 倍**。当矩阵维度悬殊时差异更大。

### 2.3 问题形式化

求最优加括号方案，使计算 $M_1 M_2 \cdots M_n$ 所需标量乘法次数最少。

## 三、动态规划求解

### 3.1 最优子结构

设 $m[i][j]$ 为计算 $M_i M_{i+1} \cdots M_j$ 的最少乘法次数。

若最优方案在 $k$ 处断开（$i \leq k < j$），先算 $M_i \cdots M_k$，再算 $M_{k+1} \cdots M_j$，最后乘起来：

$$m[i][j] = m[i][k] + m[k+1][j] + r_{i-1} \cdot r_k \cdot r_j$$

### 3.2 递推关系

$$m[i][j] = \begin{cases} 0 & i = j \\ \min\limits_{i \leq k < j}\left\{ m[i][k] + m[k+1][j] + r_{i-1} r_k r_j \right\} & i < j \end{cases}$$

### 3.3 算法伪代码

```
MatrixChainOrder(r[0..n]):
    for i ← 1 to n:
        m[i][i] ← 0
    
    for len ← 2 to n:                    // 子问题长度
        for i ← 1 to n - len + 1:
            j ← i + len - 1
            m[i][j] ← ∞
            for k ← i to j - 1:
                cost ← m[i][k] + m[k+1][j] + r[i-1] * r[k] * r[j]
                if cost < m[i][j]:
                    m[i][j] ← cost
                    s[i][j] ← k          // 记录断开位置
    
    return m[1][n]
```

### 3.4 复杂度

三层循环，每层 $O(n)$，总时间 $O(n^3)$。空间 $O(n^2)$。

## 四、DP 模式总结

### 4.1 DP 适用特征

| 特征 | 含义 |
|------|------|
| **最优子结构** | 最优解包含子问题的最优解 |
| **重叠子问题** | 子问题被反复求解 |

### 4.2 DP 设计步骤

1. 定义状态（$dp[i][j]$ 的含义）
2. 写出递推关系式
3. 确定计算顺序（自底向上或带备忘的递归）
4. 分析复杂度
