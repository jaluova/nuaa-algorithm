## 一、回溯法

### 1.1 适用范围

问题的解可表示为一个**定长向量** $X = (x_1, x_2, \ldots, x_n)$，每个分量 $x_i$ 从一个有限集合 $S_i$ 中取值。回溯法通过系统搜索解空间树来寻找满足所有约束的解。

### 1.2 核心思想

- 逐位确定解向量的分量
- 每步检查**部分解是否合法**
- 若不合法则**剪枝回溯**，不继续深入
- 若合法则继续向前，直到找到完整解

### 1.3 通用框架（定长向量 + 每维相同取值范围）

当每个 $x_i \in \{1, 2, \ldots, m\}$ 时：

```
Backtrack(k):
    if k > n:
        输出解 X[1..n]
        return
    for c ← 1 to m:
        X[k] ← c
        if IsValid(k):          // 当前部分解合法
            Backtrack(k + 1)    // 继续下一位置

// 主算法
X[1..n] ← 未初始化
Backtrack(1)
```

### 1.4 图着色问题

给定无向图 $G = (V, E)$ 和 $m$ 种颜色，给每个顶点涂一种颜色，使得相邻顶点颜色不同。

```
GraphColor(k):
    if k > n:
        输出解
        return
    for c ← 1 to m:
        X[k] ← c
        if 顶点 k 与其所有已着色邻居颜色不同:
            GraphColor(k + 1)
```

**状态分类**：
- **合法状态**：所有顶点已着色且满足约束
- **部分合法**：前 $k$ 个顶点暂不冲突
- **非法状态**：出现相邻同色冲突 → 立即回溯

### 1.5 回溯法的迭代写法

递归回溯可改写为迭代形式（用 while 循环 + 显式回退），思想等价。教材第 208 页给出了通用迭代框架。

## 二、计算复杂度理论

### 2.1 P 类问题

在**多项式时间**内可求解的判定问题（即存在一个多项式时间算法给出正确回答）。

### 2.2 NP 类问题

在多项式时间内可**验证**一个解是否正确的判定问题。即：若猜测一个解，可以在多项式时间内检查其是否正确。

显然 $P \subseteq NP$。$P \stackrel{?}{=} NP$ 是计算机科学最大的未解问题。

### 2.3 NP 完全问题

一个问题 $Q$ 是 NP 完全的，若满足：
1. $Q$ 是 NP 类问题
2. **任意** NP 类问题都可以在多项式时间内**归约**到 $Q$

若能证明某个 NPC 问题属于 P，则 $P = NP$。

### 2.4 归约

问题 $A$ 可多项式时间归约到问题 $B$（记作 $A \leq_p B$），意味着：若 $B$ 可解，则 $A$ 也可解（通过将 $A$ 的输入转换为 $B$ 的输入）。

## 三、随机算法

### 3.1 两类随机算法

| 类型 | 特点 | 例子 |
|------|------|------|
| **Monte Carlo** | 可能返回错误答案，但运行时间确定 | 随机快速选择 |
| **Las Vegas** | 若返回答案则一定正确，但可能不返回 | 随机查找众数 |

### 3.2 Las Vegas 示例：查找众数

**问题**：数组 $A[1..n]$（$n$ 为偶数），已知存在一个元素 $x$ 出现超过 $n/2$ 次，其他元素各不同且不等于 $x$。找出 $x$。

**算法**：
```
repeat:
    随机选两个不同的下标 i, j
    if A[i] = A[j]:
        return A[i]          // 必为 x
```

**正确性**：若返回，两个相同元素都等于 $x$。概率分析——每次采样命中概率 $> 1/4$，期望采样次数为常数。
