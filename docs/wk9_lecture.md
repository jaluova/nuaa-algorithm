## 一、不相交集数据结构（并查集）

### 1.1 应用场景

设全集 $U$ 有 $n$ 个元素，初始每个元素自成一个单元素子集。需要支持：
- **Find(x)**：找到 $x$ 所属子集的代表元素
- **Union(x, y)**：合并 $x$ 和 $y$ 所在的两个子集

常用于 Kruskal 最小生成树算法中判断边的两端是否属于同一连通分量。

### 1.2 数组实现

用数组 `parent[1..n]`，`parent[i]` 指向 $i$ 的父节点，根节点的 parent 为自身（或负数表示秩）。

```
// 初始化：每个元素自成一个子集
for i ← 1 to n:
    parent[i] ← i

// 查找 x 所属子集的根（带路径压缩）
Find(x):
    if parent[x] ≠ x:
        parent[x] ← Find(parent[x])   // 路径压缩
    return parent[x]

// 合并两个子集
Union(x, y):
    rx ← Find(x), ry ← Find(y)
    if rx ≠ ry:
        parent[ry] ← rx               // 简单合并，可加按秩合并优化
```

### 1.3 复杂度

使用**路径压缩 + 按秩合并**后，$m$ 次操作的总复杂度为 $O(m \cdot \alpha(n))$，其中 $\alpha$ 为反 Ackermann 函数，实际可视为常数。

## 二、最小生成树

### 2.1 问题定义

给定连通无向图 $G = (V, E)$，每条边 $(u, v)$ 有权值 $w(u, v)$。求一个无环连通子图（生成树），包含所有顶点，且边的权值总和最小。

### 2.2 贪心策略

生成树的贪心算法通用框架：每次选一条"安全边"加入当前解，保证不破坏最小生成树性质。

---

## 三、Prim 算法

### 3.1 思想

从任意起点出发，维护已选顶点集合 $X$ 和未选顶点集合 $Y = V \setminus X$。每次从跨越 $X$ 和 $Y$ 的边中选权值最小的边，将对应顶点从 $Y$ 移入 $X$。

### 3.2 数据结构

维护两个辅助数组：

| 数组 | 含义 |
|------|------|
| `nearest[v]` | $Y$ 中顶点 $v$ 到 $X$ 的边在 $X$ 中的端点 |
| `cost[v]` | 对应边的权值 |

### 3.3 算法

```
Prim(G):
    T ← ∅
    X ← {1}                          // 任选起点
    Y ← V \ {1}
    
    // 初始化
    for each v ∈ Y:
        nearest[v] ← 1
        cost[v] ← w(1, v)
    
    while Y ≠ ∅:
        选 y ∈ Y 使 cost[y] 最小
        T ← T ∪ {(y, nearest[y])}
        Y ← Y \ {y}
        
        // 更新 cost（因为 X 中新增了 y）
        for each v ∈ Y:
            if w(y, v) < cost[v]:
                cost[v] ← w(y, v)
                nearest[v] ← y
    
    return T
```

### 3.4 复杂度

朴素 $O(|V|^2)$。使用堆优化可达 $O(|E| \log |V|)$。

## 四、Kruskal 算法

### 4.1 思想

将所有边按权值从小到大排序，依次考虑每条边：若边的两端不属于同一连通分量，则选中该边并合并两个分量。

### 4.2 算法

```
Kruskal(G):
    T ← ∅
    初始化并查集：每个顶点自成一个子集
    将所有边按权值升序排序
    
    for each edge (u, v) in sorted order:
        if Find(u) ≠ Find(v):
            T ← T ∪ {(u, v)}
            Union(u, v)
    
    return T
```

### 4.3 复杂度

排序 $O(|E| \log |E|)$，并查集操作近乎 $O(|E|)$。总复杂度 $O(|E| \log |E|)$。

---

## 五、Prim vs Kruskal

| | Prim | Kruskal |
|------|------|---------|
| 策略 | 扩展顶点 | 扩展边 |
| 适合 | 稠密图 | 稀疏图 |
| 复杂度 | $O(\vert V\vert^2)$ 或 $O(\vert E\vert\log\vert V\vert)$ | $O(\vert E\vert\log\vert E\vert)$ |
| 核心数据结构 | cost 数组 | 并查集 |

## 六、快速参考

| 概念 | 要点 |
|------|------|
| 生成树 | $n$ 个顶点、$n-1$ 条边、无环、连通 |
| 割性质 | 任意割中最小权边必属于某 MST |
| 圈性质 | 任意圈中最大权边必不属于任何 MST |
| 并查集 | Find + Union，近乎常数时间 |
| 贪心正确性 | MST 满足贪心选择性质 + 最优子结构 |
