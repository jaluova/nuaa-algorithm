## 一、排序算法复习

### 1.1 插入排序

最坏比较次数：$\frac{n(n-1)}{2}$，赋值次数比比较次数多约 $(n-1)$ 次。空间 $O(1)$。

### 1.2 选择排序

每次遍历剩余元素找最小，若不在当前位置则交换。

| 指标 | 最好 | 最坏 |
|------|------|------|
| 比较次数 | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$（固定） |
| 交换赋值 | $0$ | $3(n-1)$ |

## 二、自底向上归并排序

### 2.1 核心思想

从 $n$ 个长度为 $1$ 的有序段出发，两两合并，逐层向上直到只剩一个有序段。

例（$n=8$）：$8$ 段 $\to$ $4$ 段（长度 $2$）$\to$ $2$ 段（长度 $4$）$\to$ $1$ 段（长度 $8$）

基础操作是已学过的 `merge(A, p, q, r)`，前提 $A[p..q]$ 和 $A[q+1..r]$ 各自有序，执行后 $A[p..r]$ 整体有序。

### 2.2 $n = 2^k$ 情形的算法框架

#### 下标变化规律

设当前每段长度为 $t$，两两合并时：
- 第一对：$p=1,\; q=t,\; r=2t$
- 下一对：$p \gets p+2t,\; q \gets q+2t,\; r \gets r+2t$

#### 双重循环架构

外层控制合并层数（$t$ 从 $1$ 开始，每次翻倍），内层从左到右依次合并每对有序段：

```
t ← 1
while t < n:
    p ← 1
    while r ≤ n:         // r = p + 2t - 1
        merge(A, p, p+t-1, p+2t-1)
        p ← p + 2t
    t ← 2t
```

#### 教材写法（引入 $i$ 化简）

```
t ← 1
while t < n:
    s ← t              // 保留旧的 t（合并前长度）
    t ← 2t             // 更新为新 t（合并后长度）
    i ← 0
    while i + t ≤ n:
        merge(A, i+1, i+s, i+t)
        i ← i + t
```

变量含义：
- $s$：合并前有序段长度
- $t$：合并后有序段长度
- $i$：当前处理对中第一段左端点的前一位置（从 $0$ 开始）

### 2.3 扩展到任意 $n$

当 $n \neq 2^k$ 时，某一轮合并结束后可能出现无法配对的"剩余有序段"。

**关键结论**：剩余有序段的个数只可能是 $1$ 个或 $2$ 个，不可能出现 $3$ 个。

**原因**：如果一个来自上一轮合并剩余的，一个来自本轮标准长度合并剩余的，最多 $2$ 个。

**处理方式**：
- 剩余 $1$ 段：不做任何操作，留到下一轮
- 剩余 $2$ 段：额外调用 `merge` 将两段合并

**判断方法**：内层循环结束后，检查是否还有 $2$ 个有序段（$i + s < n$），若是则额外合并：

```
if i + s < n:          // 剩余两段
    merge(A, i+1, i+s, n)
```

### 2.4 复杂度分析

设 $n$ 个元素，合并树高度为 $\lceil\log n\rceil$，每层合并总代价 $O(n)$：

- **时间复杂度**：$O(n \log n)$
- **空间复杂度**：$O(n)$（辅助数组）

与插入/选择排序的 $O(n^2)$ 相比，在大规模数据下有数量级优势。

## 三、原运算与复杂度分析基础

### 3.1 原运算概念

做算法时间复杂度分析时，我们关心的基本操作称为**原运算**（primitive operations），包括：

- 算术运算（加减乘除）
- 比较运算（大于、小于、等于）
- 逻辑运算
- 赋值操作

约定：每种原运算都计为 $1$ 次操作，不考虑不同类型运算之间的细微差别。

### 3.2 常见复杂度量级对比

从低到高：

$$1 \ll \log n \ll n \ll n\log n \ll n^2 \ll n^3 \ll 2^n \ll n!$$

**指数级的威力**（棋盘麦粒故事）：$2^{64}$ 粒麦子超过全球年产量。设计算法时必须避免指数量级。

### 3.3 $f(n)$ 与 $f(n+1)$ 的量级关系

分析 $f(n)$ 和 $f(n+1)$ 是否同量级（即 $\Theta$ 关系），看极限 $\lim_{n\to\infty}\frac{f(n)}{f(n+1)}$：

| $f(n)$ | $\lim f(n)/f(n+1)$ | 是否 $\Theta$ |
|--------|---------------------|---------------|
| $n^2$ | $1$ | 是 |
| $2^n$ | $\frac{1}{2}$ | 是（常数比） |
| $n!$ | $0$ | 否 |

多项式与指数函数都满足 $f(n) = \Theta(f(n+1))$，但阶乘不满足。

## 四、算法设计方法论

本周体现了两个核心方法论：

### 4.1 先具体后抽象

先写显式的 $p, q, r$ 变量版本（直观），再抽象为 $i$-$s$-$t$ 版本（简洁）。两种写法本质等价，抽象版本在扩展边界处理时更灵活。

### 4.2 从特例到推广

- $n = 2^k$ 特例：规律清晰，容易写出算法框架
- 推广到任意 $n$：发现剩余段问题，分类讨论（剩 $1$ 个还是 $2$ 个）
- 这就是"先解决理想情况，再处理边界"的思维模式

| 原运算约定 | 只计元素操作，不计下标 |
| 空间不计输入 | 只计额外分配的空间 |
