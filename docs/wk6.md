# wk6 作业

## 题目

设 $A[1 \cdots n]$ 和 $B[1 \cdots n]$ 是两个已按升序排列的、由互不相同的整数构成的数组。设计一个有效算法，找出 $A$ 和 $B$ 中共 $2n$ 个元素的中项，并分析算法的运行时间。

这里将“中项”定义为这 $2n$ 个元素按升序合并后第 $n$ 小的元素，也就是下中位数。

## 分析

如果直接把两个数组合并后再取第 $n$ 小元素，时间复杂度为 $O(n)$。但由于两个数组本身已经有序，可以利用“比较中位数后舍弃一半元素”的思想，把问题规模不断缩小，从而得到更高效的算法。

设当前考虑的两个子数组分别为：

- $A[l_1 \cdots r_1]$
- $B[l_2 \cdots r_2]$

它们长度始终相同，记为 $m$。

1. 若 $m = 1$，则只剩下两个元素 $A[l_1]$ 和 $B[l_2]$。  
   因为要求的是下中位数，所以答案为 $\min(A[l_1], B[l_2])$。

2. 若 $m > 1$，取两个子数组各自的中间位置：
   $$
   mid_1 = \left\lfloor \frac{l_1 + r_1}{2} \right\rfloor,\qquad
   mid_2 = \left\lfloor \frac{l_2 + r_2}{2} \right\rfloor
   $$
   记
   $$
   x = A[mid_1],\qquad y = B[mid_2]
   $$

3. 分情况讨论：

   - 若 $x = y$，则该元素就是中项，直接返回。
   - 若 $x < y$，说明 $A$ 的左半部分元素整体偏小，$B$ 的右半部分元素整体偏大。  
     因此，中项不可能出现在 $A$ 的左半段之前，也不可能出现在 $B$ 的右半段之后，可以舍去一部分元素：
     - 当 $m$ 为奇数时，保留 $A[mid_1 \cdots r_1]$ 和 $B[l_2 \cdots mid_2]$
     - 当 $m$ 为偶数时，保留 $A[mid_1 + 1 \cdots r_1]$ 和 $B[l_2 \cdots mid_2]$
   - 若 $x > y$，同理可对称处理：
     - 当 $m$ 为奇数时，保留 $A[l_1 \cdots mid_1]$ 和 $B[mid_2 \cdots r_2]$
     - 当 $m$ 为偶数时，保留 $A[l_1 \cdots mid_1]$ 和 $B[mid_2 + 1 \cdots r_2]$

每次操作后，两个子数组长度仍然相同，并且规模至少缩小一半，因此可以递归或迭代进行。

## 算法

### 伪代码

```text
Median(A, B, n):
    l1 <- 1, r1 <- n
    l2 <- 1, r2 <- n

    while l1 < r1:
        mid1 <- (l1 + r1) / 2
        mid2 <- (l2 + r2) / 2
        x <- A[mid1]
        y <- B[mid2]
        len <- r1 - l1 + 1

        if x = y:
            return x

        if x < y:
            if len is odd:
                l1 <- mid1
                r2 <- mid2
            else:
                l1 <- mid1 + 1
                r2 <- mid2
        else:
            if len is odd:
                r1 <- mid1
                l2 <- mid2
            else:
                r1 <- mid1
                l2 <- mid2 + 1

    return min(A[l1], B[l2])
```

## 正确性说明

设当前两个子数组长度都为 $m$。

- 当 $A[mid_1] < B[mid_2]$ 时，$A$ 中从左端到 $mid_1$ 附近的一部分元素一定属于较小的一批元素，而 $B$ 中从 $mid_2$ 到右端的一部分元素一定属于较大的一批元素。  
  由于我们要求的是合并后第 $n$ 小元素，因此这些“过小”和“过大”的元素可以成对舍去，而不会影响中项的位置。

- 当 $A[mid_1] > B[mid_2]$ 时，道理完全对称。

- 当两个子数组长度缩小到 $1$ 时，只剩两个候选元素，较小者就是这 $2$ 个元素中的下中位数，也就是原问题的中项。

因此，该算法能够正确返回两个有序数组合并后的中项。

## 时间复杂度

每一轮比较后，问题规模都会缩小为原来的大约一半，因此满足递推式：

$$
T(n) = T\left(\frac{n}{2}\right) + O(1)
$$

由主定理可得：

$$
T(n) = O(\log n)
$$

如果采用迭代写法，辅助空间复杂度为 $O(1)$；若采用递归写法，则递归栈空间复杂度为 $O(\log n)$。

## 结论

利用两个数组已经有序这一条件，可以通过不断比较两个子数组的中间元素并舍去不可能包含中项的部分，在 $O(\log n)$ 时间内找出这 $2n$ 个元素的中项。这比直接合并数组后再查找的 $O(n)$ 算法更高效。
