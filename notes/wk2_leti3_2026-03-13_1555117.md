## 关键概念

- **原运算 (elementary operation)**：时间分析中计入的基本操作——赋值、比较、算术运算（加减乘除）、逻辑运算。每种记作一次操作，忽略操作类型之间的细微差异。在数组场景中只计元素级运算，下标运算忽略不计。
- **大O $O(g(n))$**：上界记号。存在 $c>0$ 和 $n_0$，当 $n\ge n_0$ 时 $f(n) \le c \cdot g(n)$。大O只表示一个上界，不一定是"紧"的——$n=O(n^2)$ 在定义上也成立。
- **大Ω $\Omega(g(n))$**：下界记号。存在 $c>0$ 和 $n_0$，当 $n\ge n_0$ 时 $f(n) \ge c \cdot g(n)$。与大O完全对称。
- **大Θ $\Theta(g(n))$**：紧确界记号。同时满足 $O(g(n))$ 和 $\Omega(g(n))$，即存在 $c_1, c_2>0$ 使 $c_1 g(n) \le f(n) \le c_2 g(n)$。$\Theta$ 是对称关系：$f=\Theta(g) \iff g=\Theta(f)$。
- **极限判定法**：设 $L = \lim_{n\to\infty} f(n)/g(n)$（若极限存在）：
  - $L = 0$ 或常数 ⇒ $f=O(g)$
  - $L =$ 正常数(>0) 或正无穷 ⇒ $f=\Omega(g)$
  - $L =$ 正常数(>0) ⇒ $f=\Theta(g)$
- **大O的化简用法**：$5n^3 + 7n^2 - 2n + 13$ 可写作 $5n^3 + O(n^2)$，表示低阶项不超过 $n^2$ 的常数倍。

## 要点详述

### 原运算：分析的基本单位

算法时间复杂度的分析建立在"原运算"计数之上 [00:54]。原运算是指每次执行时间有固定上界的操作，包括：

- 算术运算（$+,-,\times,\div$）
- 比较运算（$<,>,\le,\ge,=,\neq$）
- 逻辑运算（与、或、非等）
- 赋值操作（变量赋值、指针赋值）

虽然不同运算的实际耗时有所不同（如乘法通常比加法慢），但在渐近分析中这种差异可以忽略——每种都计为一次操作 [01:37-01:55]。

一个重要的分析习惯：在数组操作中，只考虑**元素本身**涉及的运算，下标运算（如 $i++$）不计入——因为元素可能是复杂结构，其操作代价远大于下标运算 [02:34-02:48]。

### 大O：上界的定义与直觉

大O的严格定义 [03:39-04:22]：称 $f(n) = O(g(n))$，当且仅当存在一个自然数 $n_0$ 和一个常数 $c > 0$，使得对所有 $n \ge n_0$，均有：

$$f(n) \le c \cdot g(n)$$

直观理解：当 $n$ 足够大时，$f(n)$ 的增长速度不会超过 $g(n)$ 的某个常数倍。

关键认识——大O只保证一个上界，**不保证是紧的上界** [10:54-11:44]。教师用考试分数类比：考 90 分的人，可以说考 91 分的人比他高，考 100 分的人也比他高，两个都是上界。因此 $n\log n = O(n^2)$ 在定义上完全成立。

**示例**：设 $f(n) = n\log n - n + 1$ [06:59-12:00]

| $g(n)$ | $f=O(g)$? | 理由 |
|---|---|---|
| $100n\log n$ | 是 | 取 $c=200$ 可消去系数，$2n\log n$ 最终大于 $f(n)$ |
| $10n^2$ | 是 | 当 $n$ 足够大时 $10n^2 > f(n)$，满足定义 |
| $10^5 n$ | 否 | 二者比值极限为 $\infty$，无法找到常数 $c$ 使 $c \cdot 10^5 n$ 始终大于 $f(n)$ |

### 极限判定法：大O

判断 $f(n)=O(g(n))$ 最实用的方法是求极限 [12:24-13:08]。设 $L = \lim_{n\to\infty} \frac{f(n)}{g(n)}$（算法时间表达式均为非负，极限若存在则非负）：

- $L = 0$：$g(n)$ 远大于 $f(n)$，$g$ 显然是 $f$ 的上界 ⇒ 成立 [15:13-15:44]
- $L =$ 某正常数：二者增长速度同阶，取比该常数稍大的 $c$ 即可 ⇒ 成立 [16:15-16:29]
- $L = +\infty$：$f(n)$ 远大于 $g(n)$，不存在常数倍能让 $g$ 盖过 $f$ ⇒ 不成立 [16:53-17:14]

换个说法：只要极限不是正无穷，大O就成立 [17:39-17:46]。

### 大O的化简功能

大O除了表示上界，还有一个实用功能——压缩长表达式中相对次要的低阶项 [19:27-20:56]。例如：

$$f(n) = 5n^3 + 7n^2 - 2n + 13$$

可简写作：

$$f(n) = 5n^3 + O(n^2)$$

其中 $O(n^2)$ 代表"不超过 $n^2$ 常数倍的一串东西"。这样写出的表达式更简洁，且信息量无损——因为当 $n$ 足够大时，低阶项的影响远不如最高次项。

### 大Ω：下界的定义与判定

大Ω与大O完全对称 [21:55-22:42]。$f(n) = \Omega(g(n))$ 当且仅当存在 $n_0$ 和 $c>0$，使对所有 $n \ge n_0$：

$$f(n) \ge c \cdot g(n)$$

**极限判定** [24:19-27:57]：

- $L = 0$：$f$ 远小于 $g$，$g$ 不可能是 $f$ 的下界 ⇒ **不成立** [25:14-25:37]
- $L =$ 正常数(>0)：二者同阶 ⇒ 成立 [26:38-27:31]
- $L = +\infty$：$f$ 远大于 $g$，$g$ 当然是 $f$ 的下界 ⇒ 成立 [27:37-27:50]

与大O对比：大O要求极限不是正无穷，大Ω要求极限不是零。这意味着有些 $g(n)$（如与 $f(n)$ 同阶的）可以**同时**是 $f$ 的上界和下界。

**示例**（同一 $f(n)=n\log n - n + 1$）[29:56-32:08]：

| $g(n)$ | $\Omega$? | 说明 |
|---|---|---|
| $n^2/100$ | 否 | 比值极限为 0 |
| $n\log n$ | **是** | 比值极限为 1（正常数） |
| $10^5 n$ | 是 | 比值极限为 $+\infty$，$g$ 是松的下界 |

$n\log n$ 既满足大O又满足大Ω，这就引出了紧确界的概念。

### 大Θ：紧确界

当 $g(n)$ 同时是 $f(n)$ 的上界和下界时，记为 $f(n) = \Theta(g(n))$ [33:01-33:06]。正式定义：存在 $c_1, c_2 > 0$ 和 $n_0$，使对所有 $n \ge n_0$：

$$c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n)$$

即 $f(n)$ 被夹在 $g(n)$ 的两个常数倍之间 [35:05-35:24]。

大Θ可以拆解为两半 [38:39-39:58]：
- 左半边 $c_1 g(n) \le f(n)$ 就是 $f = \Omega(g)$
- 右半边 $f(n) \le c_2 g(n)$ 就是 $f = O(g)$

因此 $f = \Theta(g)$ 等价于 $f = O(g)$ 且 $f = \Omega(g)$ 同时成立。

**极限判定**：取大O和大Ω的交集——只有当 $\lim f(n)/g(n)$ 等于一个**大于 0 的常数**时，大Θ才成立 [40:23-41:07]。

**对称性**：大Θ是可互换的——$f = \Theta(g) \iff g = \Theta(f)$。因为不等式两边同取倒数后仍可凑出合适的常数 [41:50-43:08]。

### 三种记号速查表

| 判断条件 ($\lim f/g$) | $f=O(g)$ | $f=\Omega(g)$ | $f=\Theta(g)$ |
|---|---|---|---|
| $L = 0$ | 是 | 否 | 否 |
| $L = c > 0$ | 是 | 是 | **是** |
| $L = +\infty$ | 否 | 是 | 否 |

### 多项式与函数增长的示例

**多项式** [45:26-47:41]：$f(n) = a_k n^k + a_{k-1} n^{k-1} + \cdots + a_1 n + a_0$（最高次系数 $a_k > 0$），直接有 $f(n) = \Theta(n^k)$——最高次项决定了渐近量级。

**$f(n)$ 与 $f(n+1)$ 的关系** [47:46-49:36]：
- $n^2$ 与 $(n+1)^2$：比值极限为 1 ⇒ $\Theta$ 关系成立
- $2^n$ 与 $2^{n+1}$：比值极限为 2 ⇒ $\Theta$ 关系成立
- 一般地，只要 $f(n)$ 的增长是"平滑"的（非跳跃式），$f(n)$ 和 $f(n+1)$ 通常同阶
- $n!$（阶乘）：比 $2^n$ 增长更快，上节课的增长率图中尚未展示 [49:37-49:49]
