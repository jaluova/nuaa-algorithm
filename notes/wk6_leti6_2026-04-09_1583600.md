## 关键概念

- **以加换乘思想**：当乘法比加法昂贵得多时，通过增加加法次数来减少乘法次数，从而降低总计算代价
- **大整数分治**：将n位整数拆分为两个n/2位半部分，利用代数恒等式减少递归乘法调用次数
- **Strassen矩阵乘法**：2x2矩阵乘法通过7次乘法（而非8次）完成，推广到分块后时间复杂度降低
- **重叠子问题(Overlapping Subproblems)**：递归算法中同一子问题被反复求解的现象，是DP优化的直接动机
- **自底向上(Bottom-up)**：DP的核心计算策略——从小参数到大参数逐步计算并存储结果，避免重复

## 要点详述

### 负数乘法的启发 [05:00-08:54]

计算(a+bi)(c+di) = (ac-bd) + (ad+bc)i：
- 直接法：4次乘法(ac, bd, ad, bc) + 2次加减
- 优化法：`ac`, `bd`, `(a+b)(c+d)`共3次乘法，然后`ad+bc = (a+b)(c+d) - ac - bd`
- 当加法远比乘法快时，减少1次乘法的收益超过增加加减法的开销

### 大整数乘法的递推分析 [12:28-19:29]

- 直接分治（4次递归）：T(n) = 4T(n/2) + O(n) => T(n) = O(n^2)
- 优化分治（3次递归）：T(n) = 3T(n/2) + O(n) => T(n) = O(n^log3) = O(n^1.59)
- 关键恒等式：wz + xy = (w+x)(y+z) - wy - xz

### 矩阵乘法的分治优化 [20:50-31:01]

2x2矩阵乘法C = A x B：
- 定义法：4个元素 × 每个需2次乘法 = 8次乘法 + 4次加法
- Strassen法：7个中间量，每个含1次乘法（加减法增至约18次）
- 推广到n×n矩阵分块后：T(n) = 7T(n/2) + O(n^2) => O(n^log7) = O(n^2.81)

### 动态规划的核心动机 [33:07-46:33]

**斐波那契递归的问题**：fib(6)计算过程中fib(3)被重复计算3次，fib(4)被重复计算2次。递归树中大量节点被重复执行，导致时间复杂度过高（指数量级）。

**DP解决方案**：
1. 已知f1=1, f2=1
2. 从i=3到n：f(i) = f(i-1) + f(i-2)，滚动更新前两个值
3. 时间复杂度：O(n)，每个值只计算一次

**二项式系数的DP**：画出n(列)×k(行)的二维表，初始值C(n,0)=C(n,n)=1，每个内部值C(n,k)依赖于左上角C(n-1,k-1)和左边C(n-1,k)，从满足依赖关系的位置开始逐行计算。
