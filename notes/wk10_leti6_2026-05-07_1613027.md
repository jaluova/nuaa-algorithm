## 关键概念

- **递归回溯子算法**：参数 $k$ 表示当前对解向量的第 $k$ 个分量赋值。用 `for` 循环遍历 $c_k$ 的所有可能取值，赋值后判断状态并决定递归深入或回溯。当 `for` 循环自然结束（所有取值试完都不可行）时，递归返回即自动完成回溯。
- **三层判断逻辑**：每次给 $c[k]$ 赋值后，调用子算法判断当前数组处于哪种状态：(1) 全部合法 → 设 flag 为 true，算法结束；(2) 部分合法 → 递归调用自身对 $k+1$ 赋值；(3) 不合法 → 不做任何操作，for 循环自动进入下一个取值。
- **迭代版双层 while 循环**：外层控制"上下"（当前处理的层号 $k$），内层控制"左右"（当前层尝试的颜色取值）。外层条件 $k \ge 1$，内层条件 $c[k] <$ 最大取值（如 3 着色时 $c[k] \le 2$）。
- **为什么迭代必须用 while 而不用 for**：回溯发生时，上层需要从当前值的**下一个**继续尝试，而非从头开始。如果写成 `for color=1 to 3`，每次回到该层都会重新从 1 开始循环，丢失了"已经试过哪些值"的信息。用 `c[k]++` 配合 `while` 则保留了当前尝试到的位置。
- **回溯的迭代实现**：内层 while 退出意味着 $c[k]$ 的所有取值都试过且都不行 → 清空 $c[k]=0$ → $k--$（回到上一层）→ 外层循环再次进入内层时，上一层的 $c[k-1]$ 继续加一（尝试下一个值）。
- **$k$ 不会超过 $n$ 的原因**：只有在"部分合法"时才会执行 $k++$；当 $k=n$ 时，只有"全部合法"或"不合法"两种可能，不会触发 $k++$。因此 $k \le n$ 条件可加可不加。
- **四皇后问题（4-Queens）**：在 $4 \times 4$ 棋盘上放置 4 个皇后，使它们互不攻击。两个皇后相互攻击当且仅当：同行（自然避免，每行只放一个）、同列（$c_i = c_j$）、同一对角线（$|i-j| = |c_i - c_j|$）。
- **回溯法模板的通用性**：不同问题的回溯算法，差异仅在于：(1) 每个 $c_k$ 的取值范围（决定了 for/while 循环的条件）；(2) 判断"全部合法"和"部分合法"的子算法。主算法框架和回溯子算法的控制结构完全不变。
- **通用模板**：设第 $k$ 个分量的取值集合为 $X_k$。递归版：`for each v in X_k: c[k]=v; if 全部合法 → 输出; elif 部分合法 → backtrack(k+1)`。迭代版：外层 `while k>=1`，内层让 $c[k]$ 取 $X_k$ 中的下一个元素。
- **0 作为哨兵值**：当 $0$ 不在有效取值范围内时（如三着色取 $\{1,2,3\}$、四皇后取 $\{1,2,3,4\}$），可用 0 表示"未赋值/空白"的初始状态。若 0 是有意义的取值，则初始化策略需调整。

## 要点详述

### 一、递归回溯子算法的完整写法 [00:00]

上节课讲了主算法框架（初始化 + flag + 调用子算法 + 输出），本节课聚焦回溯子算法的设计 [00:20-00:37]。

**递归回溯子算法 `backtrack(k)`** [01:41-04:29]：

- 参数 $k$ 表示当前对第 $k$ 个分量（$c_k$）赋值。主算法中调用 `backtrack(1)`，从 $c_1$ 开始 [01:26-01:32]。
- 用 `for color = 1 to 3` 遍历三种颜色（三着色问题）[02:00-02:13]。
- 每次循环：$c[k] = color$，然后判断数组 $c[1..n]$ 的状态 [02:31-02:55]：

1. **全部合法（Legal）**：所有 $n$ 个顶点都着色且无冲突 → 设 `flag = true`，算法结束（回到主算法输出解）[03:08-03:47]。

2. **部分合法（Partial）**：只有部分顶点有值且无冲突 → 递归调用 `backtrack(k+1)`，对下一个分量赋值 [04:16-04:29]。

3. **不合法（冲突）**：以上两种情况都不满足（即出现了相邻同色的冲突）→ 不执行任何处理，for 循环自动进入下一轮（尝试下一个颜色）[04:43-05:01]。

> 教师指出：判断"全部合法"和"部分合法"的两个子算法假设已提前写好。递归回溯子算法本身非常简洁 [07:34-07:46]。

### 二、递归回溯中的回溯机制 [04:29]

回溯在递归版中如何发生 [05:46-06:27]：

- 当 `backtrack(k+1)` 被调用后，如果第 $k+1$ 层的 `for` 循环把三种颜色全部试完都不可行，则该函数自然返回。
- 返回到第 $k$ 层后，第 $k$ 层的 `for` 循环**继续执行下一轮**——即换下一个颜色给 $c_k$。
- 这正是回溯：$c_k$ 的当前颜色被放弃，尝试下一个颜色。回溯由递归返回自然实现，不需要显式编写回溯代码 [06:14-06:21]。

### 三、迭代版回溯法的设计动机 [07:54]

教师指出：循环迭代的写法比递归更能直观体现"回溯"的过程 [08:24-08:43]。

解空间树需要两层控制 [09:04-10:05]：

- **上下控制**：决定当前处于哪一层（$c_1$ 还是 $c_2$ 还是 $c_3$……），用变量 $k$ 表示。
- **左右控制**：决定在当前层尝试哪个取值（颜色 1、2 还是 3）。

因此，迭代版需要用**双层 while 循环**实现——外层控制上下、内层控制左右 [09:51-09:57]。而且必须先有上下控制、再有左右控制（先决定 $c_k$，再决定 $c_k$ 的取值）[10:14-10:22]。

### 四、迭代版回溯算法的外层 while 循环 [10:36]

**外层循环**控制层号 $k$ [10:57-12:05]：

- $k$ 初始值为 1（从 $c_1$ 开始赋值）。
- 循环条件：$k \ge 1$。教师解释 $k \le n$ 的条件可以加上但不必要——因为只有在"部分合法"时才会 $k++$，而当 $k=n$ 时不可能出现"部分合法"（要么全部合法找到解，要么不合法），所以 $k$ 不会超过 $n$ [21:02-21:41]。

**内层循环**控制当前层的取值 [12:55-14:13]：

内层不写成 `for color=1 to 3`，而是让 $c[k]$ 自身累加：

- 初始化时所有 $c[i] = 0$。
- 每次执行 $c[k] = c[k] + 1$（即 $c[k]++$）。
- 第一次执行：$c[k]$ 从 0 变成 1；第二次：从 1 变成 2；第三次：从 2 变成 3。
- 内层 while 条件：$c[k] \le 2$（因为颜色最大是 3，$c[k]$ 等于 3 时还可以尝试，加一之后就变成 4 了，超出范围）[13:39-13:51]。

### 五、迭代版三种状态的处理 [14:24]

在迭代版内层循环中，$c[k]$ 取一个值后，判断状态并处理 [14:24-18:37]：

1. **全部合法**：设 `flag = true`，退出两层 while 循环，算法回到主算法输出解 [14:34-15:27]。

2. **部分合法**：执行 $k = k + 1$（进入下一层）。外层循环下一次迭代会重新进入内层，对新一层的 $c[k+1]$ 从 0 开始累加 [15:28-16:23]。

3. **不合法（内层 while 自然退出）**：当 $c[k]$ 把所有颜色（1, 2, 3）都试完、每次都不满足全部合法或部分合法时，$c[k]$ 会累加到超出条件范围（如变成 4），内层 while 循环退出 [16:54-17:40]。

内层退出意味着 $c[k]$ 的所有取值都不可行 → **发生回溯** [17:40-18:37]：

- 清空 $c[k] = 0$（为后续可能的重新尝试做准备）。
- $k = k - 1$（回到上一层）。
- 外层循环再次进入时，会对上一层的 $c[k-1]$ 继续执行 `++`——即尝试上一个分量的**下一个取值**。

### 六、为什么迭代版必须用 while 而不用 for [18:37]

这是一个关键的实现细节 [19:51-21:52]：

- 如果内层写成 `for color = 1 to 3`，在回溯发生时（$k$ 减一回到上一层），for 循环会**从头开始**（$color=1$），而不是从之前尝试到的位置继续。
- 但回溯的要求是：上一层尝试**下一个**颜色，而非从 1 重新开始。
- 使用 $c[k]++$ 配合 while 的方式，$c[k]$ 的值保留了"已经试到哪儿了"——回溯回来时，$c[k-1]$ 还保持着之前的值（如 2），再加一就变成 3（下一个颜色），而不是回到 1。
- 这是递归版和迭代版在"记录状态"上的根本区别。递归版的状态通过调用栈自动保存，迭代版必须借助 $c[k]$ 自身作为状态记录器 [20:06-20:42]。

### 七、迭代版走一遍实例（含回溯） [21:52]

教师用 3-着色例子验证迭代算法 [21:52-25:40]：

**正常深入流程**（和上节课递归版一致）：
- $k=1$：$c_1$ 从 0 加至 1 → 部分合法 → $k=2$。
- $k=2$：$c_2$ 从 0 加至 1 → 不合法 → 再加至 2 → 部分合法 → $k=3$。
- 依次类推，直到 $k=5$，$c_5=3$ → 全部合法 → 退出。

**发生回溯的流程**（假设 $e \neq 3$ 的额外约束）[23:53-25:40]：
- $k=5$：$c_5$ 从 0 加至 1 → 不合法；加至 2 → 不合法；加至 3 → 不合法（因为额外约束）。
- $c_5$ 继续加至 4，超过条件 $c_5 \le 2$，内层 while 退出。
- 执行回溯：$c_5 = 0$，$k = 4$。
- 外层循环重新进入内层：$c_4$ 当前值为 1，再加一变成 2（尝试 $d=2$），然后重新开始对 $k=5$ 的尝试。

### 八、四皇后问题与回溯法模板复用 [25:40]

**四皇后问题（4-Queens Problem）** [27:22-29:12]：

- $4 \times 4$ 棋盘上放置 4 个皇后，任意两个皇后不能相互攻击。
- 攻击条件：同行（自然避免）、同列、同一对角线。
- 解用向量 $(x_1, x_2, x_3, x_4)$ 表示，$x_i \in \{1,2,3,4\}$ 表示第 $i$ 行皇后所在的列号 [28:53-29:39]。
- 判断冲突的规则 [30:00-31:44]：
  - 同列：$x_i = x_j$。
  - 同一对角线（左上→右下）：$i - j = x_i - x_j$，即行号差等于列号差。
  - 同一对角线（右上→左下）：$i + j = x_i + x_j$，即行号加列号的和相等。

**回溯算法修改（与三着色对比）** [32:57-37:19]：

教师将三着色的回溯算法直接拿来，用红色标注需要修改的地方：

| 组件 | 三着色 | 四皇后 |
|---|---|---|
| 取值范围 | $\{1,2,3\}$ | $\{1,2,3,4\}$ |
| 递归版 for | `for color=1 to 3` | `for color=1 to 4` |
| 迭代版 while 条件 | $c[k] \le 2$ | $c[k] \le 3$ |
| 向量长度 $n$ | 顶点数 5 | $n=4$ |
| 全部合法/部分合法判断 | 检查相邻顶点同色 | 检查同行/同列/同对角线 |

其余代码（主算法初始化、flag、递归调用、输出等）完全不变 [37:03-37:14]。

> 教师强调：回溯法在适用不同问题的时候，**算法几乎是一样的**——考试时直接把模板拿来、简单修改一下取值范围即可 [37:58-38:19]。

### 九、回溯法的一般化模板 [40:15]

**适用条件** [40:59-41:28]：问题的解必须表示为**定长向量** $(c_1, c_2, \dots, c_n)$，每个 $c_k$ 从有限集合 $X_k$ 中取值。即使 $X_1, X_2, \dots, X_n$ 各不相同也可以处理。

**通用递归版回溯子算法** [45:05-46:31]：

```
backtrack(k):
    for each v in X_k:        // 遍历 X_k 中的每个值
        c[k] = v
        if 全部合法:
            flag = true; 输出; return
        elif 部分合法:
            backtrack(k+1)
        // 不合法: 不做任何事, 循环继续
```

**通用迭代版回溯子算法** [46:36-47:38]：

```
k = 1
while k >= 1:
    while c[k] 还可以取 X_k 中的下一个值:
        c[k] = X_k 中的下一个值
        if 全部合法:
            flag = true; 退出两层循环
        elif 部分合法:
            k = k + 1
    // 内层退出: c[k] 所有值都试完且不行
    c[k] = 0 (或清空)
    k = k - 1
```

### 十、特殊情况模板：取值范围均为 $1..m$ [47:56]

大多数实际问题中，每个 $c_k$ 的取值范围相同，均为 $\{1, 2, \dots, m\}$ [47:56-48:09]：

- **初始化**：$c[1..n]$ 全赋为 0（0 不是有效取值，仅作为"未赋值"的哨兵）。若 0 本身是有意义的取值，则初始化方式需调整 [44:26-44:43]。
- **递归版 for**：`for x = 1 to m; c[k] = x` [48:24-48:44]。
- **迭代版 while 条件**：`while c[k] < m`（每次 $c[k]++$）[48:59-49:14]。

**模板差异总结**：不同回溯法问题之间的差异仅在于：
1. 循环条件中的取值范围（for/while 括号里的数字）。
2. "全部合法"和"部分合法"的判定逻辑（需针对具体问题单独编写，但回溯算法本身不关心其内部实现）。

其余所有代码结构（主算法的四步框架、递归/迭代的控制流）完全不变 [49:05-49:16]。

### 十一、背包问题的回溯法转化（简要提及） [49:40]

教师最后简要提到背包问题也可以用回溯法求解 [49:40-49:58]：

## 回看建议

- [00:20-04:29] 递归回溯子算法的完整三层判断逻辑（全部合法 → 改 flag，部分合法 → 递归深入，不合法 → 循环继续），这是回溯法最核心的控制流，建议默写出来。
- [04:29-07:54] 理解递归版中"回溯"如何由递归返回自然实现——子节点的 for 循环走完自动返回上层，上层 for 循环继续下一个取值。
- [10:36-18:37] 迭代版双层 while 循环的结构：外层 $k \ge 1$ 控制层号，内层 $c[k]++$ 控制取值；三种状态的分支处理；内层退出时清空 $c[k]$ 并 $k--$ 回溯。这是考试中可能要求手写的算法。
- [18:37-21:52] 为什么迭代必须用 while 而不用 for——这是易错点，关键理解：回溯时需要从"当前值的下一个"继续，而非从头开始。用 $c[k]$ 自身存状态来记忆"试到哪儿了"。
- [29:12-37:19] 四皇后问题的回溯算法——注意与三着色的对比：只改了取值范围（$1..3$ → $1..4$，即 while 条件中的 $c[k] \le 2$ → $c[k] \le 3$），其余完全不变。这说明回溯法模板的通用性。
- [44:10-49:19] 一般化模板中主算法的四步框架（初始化 + flag + 递归调用 + 输出）和回溯子算法的控制结构——这是所有回溯法问题的公共骨架，建议记牢。
