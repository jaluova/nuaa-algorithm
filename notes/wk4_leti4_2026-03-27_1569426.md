## 关键概念

- **候选人算法 (candidate algorithm)**：利用"相消配对"思想寻找多数元素的候选值——相等则计数器 +1，不等则 -1，counter 归零即意味着当前候选人被完全抵消
- **counter 归零的语义**：counter $=0$ 时，从 m 到 j 这一段中，候选值 c 与非候选值恰好成对抵消，因此这一段可以被整体丢弃，多数元素若存在必在剩余部分
- **递归改写迭代**：将尾递归（调用自身后无额外计算）中外层加 while 循环，参数更新为新值后跳回循环开头，即可消除递归
- **分治法求幂**：$x^n = (x^{\lfloor n/2 \rfloor})^2 \cdot x^{n \bmod 2}$，将规模为 $n$ 的问题递归约减到 $\lfloor n/2 \rfloor$
- **二进制展开法**：利用 $n$ 的二进制表示 $n = \sum d_i \cdot 2^i$，将 $x^n$ 分解为 $\prod x^{d_i \cdot 2^i}$，只需预计算 $x, x^2, x^4, \dots$ 再按位乘入
- **$d_i \in \{0,1\}$**：二进制位非 0 即 1，$d_i=1$ 时对应项 $x^{2^i}$ 需要乘入最终结果，$d_i=0$ 时该项为 1，可跳过

## 要点详述

### 多数元素查找：while 循环与退出分析

上一节课已经引入了"候选人算法"的基本框架。本节课从具体实现细节展开。

算法的 while 循环从位置 m 开始遍历数组，维护一个计数器 counter。比较 A[j] 与候选值 c：相等则 counter++，不等则 counter--。循环的持续条件本质上有两个：$j < n$（不越界）且 counter $> 0$（尚未被完全抵消）。但代码中 counter 条件写在循环体内的 break 语句中，因此 while 条件只需写 $j < n$。

循环结束时，存在两种相互排斥的情况：

1. **$j \ge n$ 退出（到达数组末尾）**：此时隐含着 counter $> 0$（否则早已被 break 终止），说明从 m 到末尾，候选值 c 的出现次数严格多于被抵消的次数。此时 c 就是该段的候选多数元素，直接返回 c。

2. **$j < n$ 且 counter $= 0$ 退出（中途被完全抵消）**：说明 $m$ 到 $j$ 这一段内 c 与非 c 元素两两相消，能够成对删光。若原数组存在多数元素，它不可能被完全删干净——因此多数元素必定在 $j+1$ 之后的段落中。递归调用自身，从 $j+1$ 开始新一轮查找。

### 时间复杂度为何是 O(n)

虽然算法是递归的，但无需用递推式分析。观察关键：所有数组元素只被遍历一次，不会走回头路——递归调用时起点已跳到 $j+1$，之前被抵消的段落不会再访问。因此总比较次数不超过 $n$，时间复杂度 O(n)。

验证阶段同样只需一次遍历，将候选值 c 与全部元素逐一比较并计数，也是 O(n)。

### 递归改写为循环迭代

该算法的递归属于尾递归（调用自身后没有额外计算）。改写方法：在外层加一个 while 循环，将递归调用处改为：
- $m \leftarrow j + 1$
- 重新初始化 c 和 counter
- 跳回循环开头（外层循环自动实现跳回）

核心思路不变，只是用迭代控制流代替函数调用栈。

### 整数幂运算：从 O(n) 到 O(log n)

**朴素方法**：用 for 循环连乘 $n-1$ 次，复杂度 O(n)。当 n 很大时（如密码学中的大指数）不可接受。

**快速幂的特殊情况**：若 $n$ 恰好是 2 的整数次幂（如 $n=8=2^3$），只需反复平方：$3 \to 3^2 \to 3^4 \to 3^8$，仅需 $\log_2 n$ 次乘法。

**递归分治法（通用）**：对任意正整数 n，令 $b = \lfloor n/2 \rfloor$：
- 递归计算 $t = x^b$
- 若 n 为偶数：$x^n = t^2$
- 若 n 为奇数：$x^n = t^2 \cdot x$
- 递归基：$n=1$ 时直接返回 $x$

该递归每层将问题规模减半，递归深度为 $\log n$，每层至多两次乘法，总复杂度 O($\log n$)。

### 迭代法实现：基于二进制展开

**数学基础**：将 n 写成二进制 $n = d_k 2^k + d_{k-1} 2^{k-1} + \dots + d_0 2^0$（$d_i \in \{0,1\}$），则：

$$x^n = x^{\sum d_i \cdot 2^i} = \prod_{i=0}^{k} x^{d_i \cdot 2^i}$$

每一项 $x^{d_i \cdot 2^i}$ 中：
- 若 $d_i = 1$，该项为 $x^{2^i}$
- 若 $d_i = 0$，该项为 $x^0 = 1$（可忽略）

**方法一：从低位到高位（$i=0 \to k$）**

```
y ← 1
p ← x          // p 始终保持为 x^{2^i}
for i = 0 to k:
    if d_i = 1: y ← y * p
    p ← p * p   // p 平方，准备下一轮
return y
```

每轮中，p 始终等于 $x^{2^i}$。若当前位为 1，将其乘入结果 y。循环结束后 y 即为 $x^n$。

**方法二：从高位到低位（$i=k \to 0$）**

```
y ← 1
for i = k down to 0:
    if d_i = 1: y ← y * x
    y ← y * y
return y
```

此法的精妙之处在于：先加入的 x 每经过一轮循环就会被平方一次。最早加入的（对应高位 $d_k$）会被平方 $k$ 次，恰好等于 $x^{2^k}$；后续加入的被平方次数递减。整个过程自动保证了每位对应的指数正确。

两种迭代方法的时间复杂度均为 O($\log n$)：循环共 $k+1$ 轮（$k = \lfloor \log_2 n \rfloor$），每轮至多两次乘法（一次条件乘法 + 一次平方）。
