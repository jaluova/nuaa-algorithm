## 关键概念

- **二分搜索（Binary Search）**：在有序数组中通过反复折半查找目标元素。
- **while 循环条件**：`low <= high`，含义为"搜索空间中至少还有一个元素"。
- **最坏情况分析**：每轮取剩余元素较多的一侧，计算最多需要多少轮。
- **向下取整的性质**：$\lfloor\lfloor n/2\rfloor/2\rfloor = \lfloor n/4\rfloor$（用二进制移位"显然"证明）。
- **比较次数**：最坏情况为 $\lfloor\log_2 n\rfloor + 1$。
- **数组算法的时间分析约定**：只计算元素的操作（比较、赋值、运算），忽略下标相关的所有操作。

## 要点详述

### 一、二分搜索算法补全 [05:46]

承接上一讲的内容，朱老师从"找到 middle 之后怎么做"继续写完全部算法。

**循环体**（每一轮的操作）：

1. 计算 `middle = (low + high) / 2`（向下取整）。
2. 比较 `a[middle]` 与 `x`：
   - $a[middle] = x$ → 找到，返回 middle，算法结束。
   - $a[middle] > x$ → x 只可能在左侧，搜索空间压缩为 `low` 到 `middle - 1`，即改 `high = middle - 1`。
   - $a[middle] < x$ → x 只可能在右侧，搜索空间压缩为 `middle + 1` 到 `high`，即改 `low = middle + 1`。

**循环条件**：`low <= high`。含义是：只要搜索空间至少还有一个元素，就继续搜索。一旦 `low > high`，说明所有可能的元素都已排除，循环退出。

**退出后**：返回 0（约定 0 表示"不存在"），算法结束。

> 老师强调：教科书上有另一种写法——用一个变量 `j` 记录当前可能的位置，初始为 0，效果等价，不再展开。

---

### 二、正确性证明 [10:45]

形式为分情况讨论，覆盖算法面临的所有可能。

**情况 1：数组中不存在值为 x 的元素**

- 此时 `a[middle] = x` 的条件永远不会触发。
- 每次循环必然进入"压缩搜索空间"的分支，要么 `high` 减小，要么 `low` 增大。
- 经过有限步后，必然出现 `low > high`，循环退出。
- 算法返回 0，符合预期。

**情况 2：数组中存在某个值为 x 的元素**

- 即使每次 middle 都没有命中，但搜索空间压缩时，**永远不会把 x 所在的位置排除在外**（因为比较保证了 x 一定在保留的那一侧）。
- 搜索空间不断缩小，但 x 始终在待搜索区间内。
- 最差情况下，当搜索空间只剩一个元素时，这个唯一的元素就是 x，下一轮 middle 必然命中。
- 如果数组中存在多个等于 x 的元素，该算法只会返回其中一个（命中时的下标），而非全部。

> 两种情况覆盖了算法的全部可能输入，因此算法正确。

### 三、开销分析原则 [14:21]

**空间开销**：算法只用了几个变量（low, high, middle），额外空间为常数 $O(1)$。输入的数组本身不计入额外空间。

**时间开销**：朱老师在此处给出了一个重要约定 ——

> 在分析数组类算法时，**只计算对元素的操作（比较、赋值、运算），对下标的任何操作（加减乘除、比较、赋值）一律忽略不计。**
>
> 原因：元素本身可能是复杂结构体，操作代价大；而下标是简单的整数，操作代价可忽略。

具体到二分搜索：
- `low`, `high`, `middle` 都是下标 → 不计数。
- 只有 `a[middle]` 与 `x` 的比较是对元素的 → 计数。

此外，比较虽然是"等于 + 大于"两步判断，但老师指出这实际上是一次**三路比较**（>$/$<$/$=$），只算 **1 次比较**。这是后续分析的基础。

### 四、最坏情况时间复杂度的详细推导 [17:45]

这是本节课的核心内容，推导过程共六个步骤。

#### 4.1 第一轮循环后剩余的元素个数

设数组有 $n$ 个元素，第一轮取 `middle = (1 + n) / 2`（教材中数组下标从 1 开始）。

- **如果 n 为奇数**：左边有 $(n-1)/2$ 个元素，右边也有 $(n-1)/2$ 个。最坏情况取较多一侧，剩余 $(n-1)/2 = \lfloor n/2\rfloor$。
- **如果 n 为偶数**：设 $n = 2m$，中间在 m 位置，左边 $m-1$ 个，右边 $m$ 个。最坏情况取右边 $m = n/2 = \lfloor n/2\rfloor$。

> 结论：无论 n 奇偶，最坏情况下第一轮后剩余 $\lfloor n/2\rfloor$ 个元素。

#### 4.2 逐轮推广：第 k 轮后剩余多少？

第二轮的输入是第一轮剩余的元素个数（最多 $\lfloor n/2\rfloor$），再除 2 向下取整，即 $\lfloor\lfloor n/2\rfloor / 2\rfloor$。

**关键引理**：$\lfloor\lfloor n/2\rfloor/2\rfloor = \lfloor n/4\rfloor$

**证明（二进制移位法）**：将 $n$ 表示为二进制 $b_m b_{m-1}\dots b_1 b_0$（每个 $b_i \in \{0,1\}$）。
- 除以 2 → 小数点左移一位，相当于右移一位（$b_0$ 被移出）。
- 向下取整 → 扔掉小数点后面的位（即丢弃被移出的低位）。
- 连续两次操作：右移一位并丢弃最低位，再右移一位并丢弃新的最低位，等价于直接右移两位并丢弃两个低位，即 $\lfloor n/4\rfloor$。

老师强调：二进制下除 2 就是移位，向下取整就是截断，这一性质使得多层取整可以简化到最外层。**书上可能用复杂的奇偶讨论来证明，但用移位理解显然得多。**

#### 4.3 通项公式

类推可得：**连续执行 $j$ 轮循环后，最坏情况下剩余元素个数为 $\lfloor n / 2^{j} \rfloor$**。

#### 4.4 建立不等式，求解轮数

假设最坏情况下需要执行 $j$ 轮（$j$ 为 while 循环的轮数），那么执行完第 $j-1$ 轮后，应该只剩下 1 个元素（如果再剩 2 个，可能还需要再跑一轮才能出结果）。

即：
$$\left\lfloor \frac{n}{2^{\,j-1}} \right\rfloor = 1$$

根据向下取整的定义，这意味着：
$$1 \le \frac{n}{2^{\,j-1}} < 2$$

两边乘以分母：
$$2^{\,j-1} \le n < 2^{\,j}$$

#### 4.5 取对数

对不等式取以 2 为底的对数（$\log$ 在本课程中默认底数为 2）：
$$j - 1 \le \log n < j$$

#### 4.6 得出最终结论

根据向下取整的性质：$\lfloor\log n\rfloor = j-1$，因此：

$$j = \lfloor\log_2 n\rfloor + 1$$

**最坏情况下二分搜索的元素比较次数为 $\lfloor\log n\rfloor + 1$**。每轮只做一次三路比较，所以这也等于比较次数的上界。

> 老师特别指出：算法分析往往比算法设计更复杂。二分搜索算法本身很简单，但把每一步详细分析清楚，比写算法本身更费时间。不过，**没有完善的分析，算法就是没有意义的。**

### 六、考试风格例题 [45:46]

**题目**：给定升序的正整数数组 $a[1\dots n]$（元素互不相等也可以）和一个正整数 $w$，设计一个时间复杂度为 **$O(n \log n)$** 的算法，判断数组中是否存在两个不同的下标 $i, j$，使得 $a_i^2 + a_j^2 = w$。若有，返回满足条件的任意一对下标；若无，返回不存在。

**解法思路**：外层循环 + 内层二分搜索：

```
for i = 1 to n:
    在 a[i+1 ... n] 中二分搜索等于 sqrt(w - a[i]^2) 的元素
    如果命中，返回 (i, middle)
未命中则返回不存在
```

- 外层循环跑 $n$ 次（实际到 $n-1$ 即可），每次内层做一次二分搜索（$O(\log n)$）。
- 总时间 $O(n \log n)$，满足题目要求。
- 因为数组为正整数且升序，比较结果（大于/小于）与搜索方向的关系和普通二分搜索一致，直接套用即可。

> 老师的点评："这个算法和刚才讲的二分搜索几乎一模一样，只要会了二分搜索，这道题肯定就会了。"
