## 关键概念

### 1. 有序段合并 (Merge)

- 子算法 `merge(A, p, q, r)`：将两个各自有序的子数组 $A[p..q]$ 与 $A[q+1..r]$ 合并成一个有序的 $A[p..r]$。
- **前提条件**（调用前必须满足）：$A[p..q]$ 有序、$A[q+1..r]$ 有序。
- **后置条件**（调用结束后）：$A[p..r]$ 整体有序。
- 这是整节排序算法构建的**唯一基础操作**。

### 2. 自底向上合并排序的树形结构

- 将数组看作一棵完全二叉树的叶子，每一轮合并对应向上一层。
- 执行顺序：从叶子（长度为 $1$ 的有序段）向根（长度为 $n$ 的有序段）逐层合并。
- 与递归的自顶向下归并排序（后面章节）执行顺序不同，但逻辑结构相似。

### 3. 核心算法框架（$n = 2^k$）

```
t ← 1
while t < n:
    s ← t          // 保存旧的 t
    t ← 2t         // 更新为新 t（合并后的长度）
    i ← 0
    while i + t ≤ n:
        merge(A, i+1, i+s, i+t)
        i ← i + t
```

**变量含义**：
- $t$：当前轮次中**合并后**有序段的长度（外层控制）
- $s$：当前轮次中**合并前**有序段的长度（$s = t/2$）
- $i$：当前正在处理的一对有序段中，第一段左端点的前一位置（从 $0$ 开始，方便用 $i+1$ 取下标）

### 4. 下标变化规律

对长度为 $t$ 的有序段做两两合并时，设第一对参数为 $(p_1, q_1, r_1)$：
- $p_1 = 1$（数组下标从 $1$ 开始计数）
- $q_1 = t$
- $r_1 = 2t$

下一对：$p_2 = p_1 + 2t$，$q_2 = q_1 + 2t$，$r_2 = r_1 + 2t$

一般递推：$p_{k+1} = p_k + 2t$（步长 = 合并后长度 = $2t$），$q$、$r$ 同步。

### 5. 使用变量 $i$ 的化简

引入 $i$（初始 $i=0$），令：

$$p = i+1,\quad q = i+s,\quad r = i+t$$

一轮合并后，`i ← i + t` 自动完成 $p, q, r$ 的步进（因为 $t$ 已经更新为合并后长度，即 $2 \times$ 旧 $t$）。

两种写法的本质等价：
- 显式 $pqr$ 写法：更直观，但需分别维护三个变量
- $i$-$s$-$t$ 写法（教材）：写出更简洁，尤其在扩展到任意 $n$ 时更容易处理边界

### 6. 扩展到任意 $n$ — 剩余段处理

当 $n \neq 2^k$ 时，某一轮合并结束后可能出现无法配对的「剩余有序段」。

**关键结论**：
- 剩余有序段的个数只可能是 **1 个** 或 **2 个**，不可能出现 $3$ 个。
- 原因：每一轮只要发现多于 $1$ 个就做合并，下轮最坏情况是"前面合并剩的 $1$ 个 + 本轮新剩的 $1$ 个 = $2$ 个"。
- 处理方式：
  - 剩余 **$1$ 段**：不做任何操作（长度不够的短段留到下一轮）
  - 剩余 **$2$ 段**：额外调用 `merge` 将两段合并为一段

## 要点详述

### 插入排序复习要点

- 最坏比较次数：$\frac{n(n-1)}{2}$
- 赋值次数比比较次数多一次
- 上节课作业：将插入排序算法"倒过来写"——多数同学完成，4 人未交

### 选择排序复习要点

- 基本操作：遍历剩余元素找最小，若不在当前位置则交换
- 比较次数恒为 $\frac{n(n-1)}{2}$（与数据分布无关）
- 赋值（交换）次数：
  - 最坏：每轮都交换，$n-1$ 轮 $\times$ 每次 $3$ 次赋值 = $3(n-1)$
  - 最好：$0$ 次（已有序）

### 合并排序的"分治"直觉

- 并未显式提「分治法」，但思路已经暗含
- 核心是利用已有子程序（有序段合并）来构建更强大的排序
- 参数设计（$pqr \to i$-$s$-$t$）体现了"先具体后抽象"的算法设计方法论
