# 第3周第3节 · 几乎完全二叉树与堆

**日期:** 2026-03-20 | **教师:** 朱友文

## 本节主线

本讲从完全二叉树的编号性质出发，引出"几乎完全二叉树"（almost complete binary tree）的概念与性质；进而说明这种编号方案的核心意义——可以用数组存储二叉树而无需任何指针，父子关系完全通过下标算术运算（乘 2、除以 2 向下取整）维护。随后严格推导了几乎完全二叉树的高度公式 $h = \lfloor \log_2 n \rfloor$，并正式引入**堆（heap）**这一数据结构：堆是一棵几乎完全二叉树，且满足任意父节点元素值 $\ge$ 子节点元素值（大顶堆）。最后讨论了堆在"频繁插入 + 频繁求最大/最小值"场景下的性能优势——插入 $O(\log n)$、求最值 $O(1)$。

## 关键概念

- **完全二叉树（Complete Binary Tree）**：除最下层外每层节点数均满（第 $k$ 层 $2^k$ 个），且最下层的节点全部靠左连续排列。
- **从上往下、从左往右编号**：根节点编号为 $1$，同一层内从左往右依次递增，逐层向下。这种编号是数组存储的基础。
- **编号的父子关系**：编号为 $m$ 的节点，左孩子编号 $2m$，右孩子编号 $2m+1$；父节点编号 $\lfloor m/2 \rfloor$。
- **几乎完全二叉树（Almost Complete Binary Tree）**：从一棵完全二叉树的最下层最右侧起**连续删除**若干个节点后剩余的部分。完全二叉树是其特例。
- **叶子节点个数公式**：已知节点总数 $n$，叶子数 $= n - \lfloor n/2 \rfloor = \lceil n/2 \rceil$（完全二叉树和几乎完全二叉树均适用）。
- **数组存储无指针方案**：利用编号的连续性，将几乎完全二叉树存入数组 $H[1\dots n]$；父子关系通过下标算术（$\times 2$, $\div 2$ 取整）隐式维护，无需存储指针。
- **几乎完全二叉树的高度**：$h = \lfloor \log_2 n \rfloor$（根在第 $0$ 层，高度为 $h$）。
- **堆（Heap）**：一棵几乎完全二叉树，且满足堆序性质——大顶堆中每个节点的值 $\ge$ 其所有子节点的值；小顶堆反之。
- **堆的插入与求最值复杂度**：插入 $O(\log n)$（高度量级），求最大值 $O(1)$（根节点）。
- **第二大元素**：在大顶堆中必为根节点的左孩子或右孩子之一，一次比较即可确定。

## 要点详述

### 一、完全二叉树的编号回顾 [00:00–02:00]

上节课建立了完全二叉树的编号方案：从上往下、从左往右，根节点编号 $1$，依次递增。对于编号为 $m$ 的任意非叶节点：

- 左孩子编号：$2m$
- 右孩子编号：$2m+1$

证明思路：设该节点在第 $x$ 层、左起第 $y$ 个，则其编号为 $2^x + y - 1$；左孩子在 $x+1$ 层、左起第 $2y-1$ 个，编号为 $2^{x+1} + 2y - 2 = 2(2^x + y - 1) = 2m$。右孩子紧随其后，编号为 $2m + 1$ [01:12–01:59]。

### 二、从孩子反推父节点 [02:00–04:31]

根据上述二倍关系，反向推导也成立。设某节点编号为 $m$：

- 若 $m$ 为**偶数**：该节点是左孩子，父节点编号为 $m/2$
- 若 $m$ 为**奇数**：该节点是右孩子，父节点编号为 $(m-1)/2$

两种情况可统一写为一个简洁的公式：

$$\text{parent}(m) = \lfloor m / 2 \rfloor$$

这是因为 $m$ 为偶数时 $\lfloor m/2 \rfloor = m/2$；$m$ 为奇数时 $\lfloor m/2 \rfloor = (m-1)/2$ [03:36–04:01]。

### 三、叶子节点个数（完全二叉树）[04:31–07:01]

对于节点总数为 $n$ 的完全二叉树，最后一个非叶节点的编号是 $\lfloor n/2 \rfloor$（因为需要给其孩子留出编号空间）。因此：

- 非叶节点个数：$\lfloor n/2 \rfloor$
- 叶子节点个数：$n - \lfloor n/2 \rfloor = \lceil n/2 \rceil$

可通过奇偶讨论验证：
- $n$ 为偶数：$\lfloor n/2 \rfloor = n/2$，叶子数 $= n - n/2 = n/2$
- $n$ 为奇数：$\lfloor n/2 \rfloor = (n-1)/2$，叶子数 $= n - (n-1)/2 = (n+1)/2 = \lceil n/2 \rceil$

两种情况均可统一为 $\lceil n/2 \rceil$ [05:42–06:20]。

### 四、几乎完全二叉树的定义 [07:01–09:05]

这是本讲引入的第一个核心概念。

**定义**：从一棵**完全二叉树**的**最下层**中，从**最右侧**起**连续**删除若干个节点（可以是 $0$ 个），剩余部分称为**几乎完全二叉树**。

三个关键约束：
1. 必须基于完全二叉树操作
2. 只能删除最下层的节点
3. 必须从最右侧起**连续**删除（不能跳着删除）

按照之前的编号方案，删除的是"编号最大的连续若干节点"，因此剩余节点的编号仍保持 $1$ 到某个值 $k$ 的连续性，编号之间的二倍关系依然成立 [08:18–08:54]。

**与完全二叉树的区别**：几乎完全二叉树的叶子节点不一定全部在最下层——如果删除的节点包括某个非叶节点的全部孩子，该非叶节点就变成了叶子节点。因此叶子节点可能出现在倒数第一层**或**倒数第二层 [09:13–09:45]。

**叶子数公式依然适用**：由于编号方案不变（只删除了尾部节点），$\lceil n/2 \rceil$ 的结论仍然成立 [10:00–10:49]。

### 五、编号的意义——数组存储无指针方案 [11:36–16:07]

这是整个编号方案的设计动机。

**核心思想**：由于编号从 $1$ 到 $n$ 是连续的，我们可以直接将每个节点存入数组的第 $i$ 个位置（$H[i]$），形成一个普通的线性数组。物理存储上是数组，逻辑结构上仍是一棵树。

**父子关系的保持**（无需额外指针）：

| 操作 | 下标运算 |
|---|---|
| 从节点 $j$ 找左孩子 | $2j$ |
| 从节点 $j$ 找右孩子 | $2j+1$ |
| 从节点 $j$ 找父节点 | $\lfloor j/2 \rfloor$ |
| 从节点 $j$ 找兄弟节点 | 若 $j$ 为偶数则 $j+1$，若 $j$ 为奇数（且非根）则 $j-1$ |

**意义**：在内存中仅需申请一个存放元素值的数组，不需要额外的空间存储指针或引用，父子关系通过下标算术运算隐式维护 [14:35–15:12]。这既节省空间，又保持了遍历和查找等操作的高效性。

### 六、几乎完全二叉树的高度推导 [18:35–27:03]

这是本讲的第一个重要证明。设树的高度为 $h$（根在第 $0$ 层，最下层为第 $h$ 层），节点总数为 $n$。

**不等式的建立**：

前 $h$ 层（第 $0$ 层至第 $h-1$ 层）是满的，节点数之和为：

$$2^0 + 2^1 + \cdots + 2^{h-1} = 2^h - 1$$

第 $h$ 层（最下层）的节点数至少为 $1$（因为是几乎完全二叉树，最下层一定存在），最多为 $2^h$（满层情况）。因此：

$$(2^h - 1) + 1 \;\le\; n \;\le\; (2^h - 1) + 2^h$$

即：

$$2^h \;\le\; n \;\le\; 2^{h+1} - 1$$

将右端放大一点（去掉 $-1$），得到更简洁的形式：

$$2^h \le n < 2^{h+1}$$

**取对数求解 $h$**：对不等式各部分取以 $2$ 为底的对数：

$$h \le \log_2 n < h + 1$$

根据向下取整的定义，$\lfloor \log_2 n \rfloor = h$，因此：

$$\boxed{h = \lfloor \log_2 n \rfloor}$$

**结论**：只要知道几乎完全二叉树的节点总数 $n$，它的高度就是 $\lfloor \log_2 n \rfloor$，与最下层有多少个节点无关 [26:52–27:23]。

### 七、堆的引入动机 [28:05–34:46]

在引入堆之前，老师先给出了一个实际应用场景：

**需求**：需要一个数据结构同时支持两个高频操作——
1. 不断插入新元素
2. 频繁查询当前所有元素中的最大值（或最小值）

**现有方案的不足**：

| 方案 | 插入 | 求最值 | 问题 |
|---|---|---|---|
| 普通数组（不排序） | $O(1)$，直接放末尾 | $O(n)$，需遍历全部 | 求最值太慢 |
| 有序数组（保持有序） | $O(n)$，需找到位置并移动 | $O(1)$，直接取首/尾 | 插入太慢 |

两种方案都有一端是线性复杂度。**堆**能做到两头兼顾：

| 操作 | 堆的时间复杂度 |
|---|---|
| 插入 | $O(\log n)$ |
| 求最大值 | $O(1)$ |

插入从 $O(n)$ 降到 $O(\log n)$ 的原因是：堆是一棵几乎完全二叉树，其高度为 $\lfloor \log n \rfloor$，而插入操作只需沿树高方向调整 [34:12–34:46]。

### 八、堆的正式定义 [34:46–37:23]

**堆是一个满足以下两个条件的数据结构：**

1. **结构条件**：堆是一棵**几乎完全二叉树**
2. **堆序条件**：对于堆中任意一个非根节点，其元素值**不超过**其父节点的元素值（大顶堆定义）

即对任意父子对 $(parent, child)$：
$$H[parent] \ge H[child]$$

由此立即可得：在大顶堆中，**根节点存储的是最大元素** [36:44–37:03]。

> 若需要最小值在根节点，则将不等号反向即可得到**小顶堆**。本课程后续以**大顶堆**为例展开。

### 九、堆的存储与基本操作 [37:23–44:43]

**数组表示**：堆用数组 $H[1\dots n]$ 存储，其中 $n$ 为当前堆中的元素个数。$H[1]$ 为根节点。

**下标关系表**（对于节点 $j$）：

| 关系 | 下标 |
|---|---|
| 父节点（$j>1$） | $\lfloor j/2 \rfloor$ |
| 左孩子（若存在） | $2j$ |
| 右孩子（若存在） | $2j+1$ |
| 兄弟节点 | $j$ 为偶数时 $j+1$，奇数时 $j-1$（非根） |

这些关系完全继承自几乎完全二叉树的编号性质，无需额外证明 [41:54–42:01]。

**堆的高度**：直接套用几乎完全二叉树的高度公式——$n$ 个节点的堆高度为 $\lfloor \log_2 n \rfloor$ [43:50–44:05]。

### 十、堆的若干补充性质 [44:43–49:57]

1. **根节点最大**：由堆序条件的传递性，根节点的元素值大于等于所有子孙节点，因此是最大元素 [45:04–45:07]。

2. **从根到叶的路径递减**：沿任意一条从根到叶子的路径，元素值单调不增 [45:23–45:32]。

3. **叶子节点值较小，但叶节点之间无序**：堆序条件只约束父子关系，不约束兄弟关系，因此所有叶子节点之间的大小关系是未知的，无法直接确定谁大谁小 [45:54–46:14]。

4. **第二大元素**：必在根节点的左孩子、右孩子中——二者比较一次即可确定，操作代价为 $O(1)$ [47:22–47:48]。

5. **第三大及之后**：可能需要比较更多节点（如左孩子的孩子、右孩子等），候选范围快速扩大，堆不再是最优选择 [48:04–48:36]。

6. **最小元素**：必在叶子节点中，但叶子节点之间无序，因此求最小值需遍历所有叶子节点。叶子数约 $\lceil n/2 \rceil$，时间复杂度为 $O(n)$。这说明**堆擅长求最大值，不擅长求最小值**（在大顶堆定义下） [48:51–49:44]。
