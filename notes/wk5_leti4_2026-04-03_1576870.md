## 本节主线

本讲围绕 BFPRT 线性时间选择算法的后半部分展开，完成三项核心任务：

1. **设计原地分划算法**：从两路分划（小于等于 pivot / 大于 pivot）出发，用双指针 i/j 维护循环不变量，再自然扩展到三路分划（小于 / 等于 / 大于 pivot），全程无需辅助数组。
2. **串接完整选择流程**：将"中位数的中位数"候选值 mm、三路分划、递归到 A1 或 A3 串联起来，得出第 k 小元素选择算法的完整实现。
3. **证明 O(n) 时间复杂度**：通过中位数图分析 A1 与 A3 的元素个数上界（≤ 3n/4），推导递归式 $T(n) \le T(n/5) + T(3n/4) + O(n)$，最终解出 $T(n) = O(n)$，并指出常数系数约在 60–80 之间。

## 关键概念

- **两路分划（Two-way Partition）**：给定 pivot 值 mm，将数组 A[low..high] 在原有存储空间上重排为两段——左侧连续若干个元素 ≤ mm，右侧连续若干个元素 > mm。一趟遍历即可完成。
- **循环不变量（Loop Invariant）**：遍历过程中始终维持：已处理区域 A[low..i] 全部 ≤ mm，A[i+1..j] 全部 > mm。i 标记"≤ 区域"的右边界，j 为当前遍历位置。
- **指针 i（分界指针）**：指向"≤ pivot 区域"的最后一个元素。初始值 $i = low - 1$，表示初始时该区域为空。每次发现 ≤ mm 的元素时 i 前进一格并与 j 处交换。
- **指针 j（遍历指针）**：从 low 遍历到 high−1（或 high），逐一检查每个元素与 mm 的大小关系。遇大于 mm 则直接前移（自动归入 > 区域）。
- **三路分划（Three-way Partition）**：在两路分划的基础上，对"≤ mm"这一半再做一层划分，用指针 t 从右向左遍历，分离出"等于 mm"的区域。最终形成 A1（< mm）、A2（= mm）、A3（> mm）三段。
- **指针 t（等值分界指针）**：在三路分划第二阶段使用，标记"= mm 区域"的左边界。初始值 $t = i + 1$（等于区域初始为空）。遇等于 mm 的元素时 t 减一并与 j 交换。
- **W 区域（蓝色框）**：在中位数图中，位于候选值 mm 左下方的一块矩形区域。该区域内所有元素均 ≤ mm，因此 $W \subseteq A_1 \cup A_2$，用于推导 A1+A2 的元素个数下界。
- **X 区域（粉色框）**：与 W 对称的区域，位于 mm 右上方。该区域内所有元素均 ≥ mm，因此 $X \subseteq A_2 \cup A_3$，用于推导 A1 的元素个数上界。
- **向上/向下取整的放缩**：在推导上界时反复使用两个技巧——(1) 去掉向上取整使值变小（得下界），(2) 将向下取整替换为 $\lfloor n/5 \rfloor \ge (n-4)/5$（得下界），从而在不等式中层层放大得出上界。
- **递归式**：$T(n) \le T(\lfloor n/5 \rfloor) + T(\max(|A_1|, |A_3|)) + \Theta(n)$，其中 $\max(|A_1|, |A_3|) \le 3n/4$，代入求解得 $T(n) = O(n)$。
- **常数系数**：尽管 $T(n) = O(n)$，但 $1 - 1/5 - 3/4 = 1/20$ 导致系数放大为约 60–80，意味着该算法在小规模数据上不如简单方法，仅在 n 非常大时才体现优势。
- **递归方向唯一性**：第 k 小元素只可能落在 A1、A2、A3 之一——若在 A2（$k \in [|A_1|+1, |A_1|+|A_2|]$）则直接返回 mm；否则只需递归进入 A1 或 A3 其中之一。

## 要点详述

### 一、两路分划算法设计 [01:43]

从"如何把一个无序数组的若干个连续元素分成两段"出发，朱老师提出两路分划的核心思想。

**目标**：给定数组 A[low..high] 和一个值 mm（pivot），重排数组使得——左侧所有元素 ≤ mm，右侧所有元素 > mm。

**循环不变量设计** [02:09–03:44]：

引入两个指针：
- $j$：遍历指针，从 low 向后扫描
- $i$：分界指针，标记"≤ mm 区域"的右边界

在遍历的任意时刻，维持以下状态：

$$A[low..i] \le mm,\quad A[i+1..j-1] > mm$$

即已遍历过的区域已经达到了分两段的目标。

**处理逻辑** [03:44–05:29]：

每步检查 $A[j]$ 与 mm 的关系：
- 若 $A[j] > mm$：不做任何操作，j 直接后移（该元素自动归入右侧 > 区域）
- 若 $A[j] \le mm$：i 前进一格（i++），然后交换 A[i] 与 A[j]，j 后移

这样一来，每处理一个新元素，只做一次比较和最多一次交换，就能维持循环不变量。

**初始值** [05:42–06:34]：

- $j$ 初始值 = low（从第一个元素开始遍历）
- $i$ 初始值 = low − 1（表示 ≤ mm 区域初始为空——下标最大值比最小值还小，对应空区间）

> 朱老师解释：要使 A[low..i] 没有元素，只要让 i 比 low 还小即可。

### 二、两路分划伪代码 [06:41]

```
i = low - 1
for j = low to high-1:
    if A[j] <= mm:
        i = i + 1
        if i != j:         // 避免同位置自交换
            swap(A[i], A[j])
```

交换前判断 $i \neq j$ 的理由 [09:25–09:56]：数组元素交换需要三次赋值操作，若 i 与 j 指向同一位置，可直接跳过以节省开销。

遍历结束时，数组自然分成两块：
- $A[low..i]$：全部 ≤ mm
- $A[i+1..high]$：全部 > mm

### 三、三路分划算法 [10:34]

在两路分划完成后，进一步将"≤ mm"区域划分为"< mm"与"= mm"两段。

**做法**：对 $A[low..i]$ 再做一趟遍历（反向），用指针 t 标记"= mm 区域"的左边界。

**目标状态**：

$$A[low..t-1] \; (< mm),\quad A[t..i] \; (= mm),\quad A[i+1..high] \; (> mm)$$

**指针与初始值** [13:41–15:17]：

- $j$：从 i 递减遍历至 low（反向扫描 A[low..i] 区间）
- $t$：等值分界指针，初始值 $t = i + 1$（= mm 区域初始为空）

**处理逻辑** [15:17–16:13]：

每步检查 $A[j]$：
- 若 $A[j] < mm$：不做操作，j 继续前移
- 若 $A[j] = mm$：t 减一，交换 A[t] 与 A[j]，j 前移

**伪代码**：

```
t = i + 1
for j = i downto low:
    if A[j] == mm:
        t = t - 1
        swap(A[t], A[j])
```

最终三个区域的下标范围 [16:34–17:43]：
- $A_1$（< mm）：$A[low..t-1]$
- $A_2$（= mm）：$A[t..i]$
- $A_3$（> mm）：$A[i+1..high]$

> 朱老师补充：也可以用一层 for 循环直接完成三路分划（类似荷兰国旗问题），但逻辑更复杂，有兴趣可自行尝试 [19:22–19:37]。

### 四、完整选择算法串联 [17:48]

整个第 k 小元素选择算法的三步：

1. **求候选值 mm**（上节课内容）：将 n 个元素 5 个一组排序，取每组中位数，再递归求中位数的中位数。
2. **三路分划**：以 mm 为 pivot，原地划分为 $A_1, A_2, A_3$。
3. **递归搜索**：根据 k 落在哪个区域决定——
   - 若 $k \le |A_1|$：递归到 $A_1$ 中找第 k 小
   - 若 $|A_1| < k \le |A_1| + |A_2|$：直接返回 mm
   - 否则：递归到 $A_3$ 中找第 $k - |A_1| - |A_2|$ 小

元素个数计算只需下标减法 [17:26–17:43]：
$$|A_1| = t - low,\quad |A_2| = i - t + 1,\quad |A_3| = high - i$$

### 五、时间复杂度分析动机 [19:41]

朱老师强调：如果绕了一大圈（5 个一组、递归调度、三路分划），最终时间复杂度还不如直接排序的 $O(n \log n)$，这个算法就毫无设计价值。因此必须严格证明 $T(n) < O(n \log n)$，目标为 $O(n)$。

**分步代价** [21:07–22:55]：

| 步骤 | 时间代价 |
|---|---|
| 5 个一组单独排序 | $O(n)$（每组排序常数时间，共 $q = \lfloor n/5 \rfloor$ 组） |
| 递归求 mm | $T(\lfloor n/5 \rfloor)$ |
| 三路分划 | $O(n)$（一至两趟遍历） |
| 递归到 A1 或 A3 | $T(\max(|A_1|, |A_3|))$ |

核心问题：$|A_1|$ 和 $|A_3|$ 最多能有多大？

### 六、中位数图与 W 区域分析 [24:19]

将所有 $\lfloor n/5 \rfloor$ 组的中位数按升序排列。对每一组，假设 5 个元素已分别排好序——中位数上方有 2 个比它大的，下方有 2 个比它小的。将这些元素全部画出，形成一个 $5 \times q$（近似）的矩阵。

**候选值 mm** 是这些中位数的中位数——即位于整个中位数列的中间位置。

**W 区域（蓝色框）** [28:09–29:03]：

以 mm 所在列及其左边所有列为范围，取每一列的中位数及其中位数的下方 2 个元素，形成一块矩形区域 W。该区域内所有元素均 ≤ mm——

理由：同行向左递减（中位数升序），同列向上递增（组内已排序），因此 W 中每个元素都 ≤ 它所在列的中位数 ≤ mm。

于是 $W \subseteq A_1 \cup A_2$，即：

$$|A_1| + |A_2| \ge |W|$$

**W 的大小** [30:57–31:40]：

W 有 $\lceil q/2 \rceil$ 列（mm 及其左边的所有中位数），每列 3 个元素（中位数 + 下方 2 个）：

$$|W| = 3 \times \left\lceil \frac{q}{2} \right\rceil,\quad q = \left\lfloor \frac{n}{5} \right\rfloor$$

### 七、A3 上界的逐层放缩 [33:01]

$$|A_3| = n - (|A_1| + |A_2|) \le n - 3 \cdot \left\lceil \frac{\lfloor n/5 \rfloor}{2} \right\rceil$$

**第一步**：去掉外层向上取整（值只会更小或相等 → 下界）：

$$|A_3| \le n - \frac{3}{2} \left\lfloor \frac{n}{5} \right\rfloor$$

**第二步**：处理向下取整。设 $t = n \bmod 5$（$0 \le t \le 4$），则：

$$\left\lfloor \frac{n}{5} \right\rfloor = \frac{n - t}{5} \ge \frac{n - 4}{5}$$

代入（减数变小 → 整体变大）：

$$|A_3| \le n - \frac{3}{2} \cdot \frac{n - 4}{5} = n - \frac{3(n-4)}{10}$$

$$= n - 0.3n + 1.2 = 0.7n + 1.2$$

**第三步**：利用阈值 $n \ge 44$（规模小于 44 时直接排序，不计入递归）：

$$0.05n \ge 44 \times 0.05 = 2.2 \ge 1.2$$

因此：

$$|A_3| \le 0.7n + 0.05n = 0.75n = \frac{3}{4}n$$

### 八、A1 上界的对称推导 [40:56]

对称地圈出**粉色区域 X**——以 mm 及其右边所有列，取每列中位数及其上方 2 个元素。X 中所有元素均 ≥ mm，$X \subseteq A_2 \cup A_3$。

完全对称的推导可得：

$$|A_1| = n - (|A_2| + |A_3|) \le n - |X| \le n - \frac{3}{2} \left\lfloor \frac{n}{5} \right\rfloor \le \frac{3}{4}n$$

**结论**：无论递归进入 A1 还是 A3，子问题规模均不超过原规模的 $3/4$。

### 九、递归式求解与常数系数 [46:24]

代入上界，得递归式：

$$T(n) \le T\left(\left\lfloor\frac{n}{5}\right\rfloor\right) + T\left(\frac{3}{4}n\right) + O(n)$$

朱老师用系数叠加法求解（适用于形如 $T(n) \le T(an) + T(bn) + cn$ 的递归式，其中 $a + b < 1$）：

$$T(n) \le \frac{cn}{1 - a - b} = \frac{cn}{1 - 1/5 - 3/4} = \frac{cn}{1/20} = 20c \cdot n$$

**常数 c 的估算** [48:22–48:56]：
- 5 个元素排序约需 10 次比较 → 平均每个元素 $10/5 = 2$ → $c_1 \approx 2$
- 分划需要至多两趟遍历 → $c_2 \approx 2$
- 合计 $c \approx 4$，故 $T(n) \approx 80n$

**实际意义** [48:57–49:19]：

虽然在量级上是 $O(n)$（优于排序的 $O(n \log n)$），但前面的常数系数较大（60–80），意味着当 n 不够大时，直接排序可能反而更快。只有 n 非常大时，该算法的渐近优势才能体现。

- **[46:24–48:56]** 递归式求解与常数计算——$a + b = 19/20 < 1$ 是递归式收敛的关键，理解 $1/(1-a-b)$ 如何放大系数，以及常数 c 的来源（排序 + 分划）。
