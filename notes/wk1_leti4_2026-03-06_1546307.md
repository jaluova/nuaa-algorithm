## 时间轴

### [00:00] 无辅助空间合并：从最简单情形出发

**教学动作**：回顾上节内容，提出核心问题——没有辅助数组，如何将两个有序段合并？

- 先考虑最极端的情形：后半段只有一个元素 $x = a[q+1]$，前半段 $a[p \ldots q]$ 已有序。
- 基本思路：从 $q$ 向前遍历，所有比 $x$ 大的元素依次后移一格，腾出的空位放 $x$。

**[01:17] 板书：单元素合并算法（初版）**

```
s = q;
while (s >= p && a[s] > x) {
    a[s+1] = a[s];
    s = s - 1;
}
a[s+1] = x;
```

- $s$ 指向当前比较的元素，从 $q$ 往前扫描。
- 若 $a[s] > x$，将 $a[s]$ 后移一格，$s$ 减 1 继续向前比较。
- 若 $a[s] \le x$，说明所有 $>x$ 的元素已移完，$a[s+1]$ 位置空出，将 $x$ 放入。

### [07:17] 极端情况分析，发现并修正算法缺陷

**教学动作**：引导学生用极端值验证算法的正确性。

#### 极端情况一：$x$ 大于前面每一个元素

- $a[q] \le x$，`while` 条件不成立，直接执行 `a[s+1] = x`。
- $s$ 此时等于 $q$，$s+1 = q+1$，$x$ 留在原位，正确。
- **但需补充 `break`**：若通过比较找到位置，插入后应立即跳出循环；PPT 上统一将赋值放到末尾，可避免漏写 `break`。

#### 极端情况二：$x$ 小于前面每一个元素

- $a[p \ldots q]$ 每个元素都 $>x$，`while` 循环一直执行，直到 $s$ 减到 $p-1$（不满足 $s \ge p$）才退出。
- $a[s+1]$ 中的所有元素均已后移一格，但 **$x$ 未被写入**！
- **修正**：退出循环后需补一条 `a[s+1] = x`（此时 $s+1 = p$），将 $x$ 放到 $a[p]$。

> **朱老师强调**：极端情况最容易发现错误。两种极端情况（$x$ 最大、$x$ 最小）都正确后，中间情况自然正确。

### [13:24] 推广到多元素：外层加循环

**教学动作**：从解决一个简单问题到推广到更复杂问题——"如果一个复杂的问题解决不了，先考虑简单问题，再回头看能否改进扩展。"

- 当后半段有多个元素（$a[q+1 \ldots r]$），只需**外层再加一层循环**：
  - 引入下标 $i$，从 $q+1$ 遍历到 $r$，每次将 $a[i]$ 合并到前面已有序的 $a[p \ldots i-1]$ 段中。
  - 内层逻辑不变，只需将原算法中的 $q$ 替换为 $i-1$，$x = a[q+1]$ 替换为 $x = a[i]$。

**[15:52] 完整算法结构：**

```
for (i = q+1; i <= r; i++) {
    x = a[i];
    s = i - 1;
    while (s >= p && a[s] > x) {
        a[s+1] = a[s];
        s = s - 1;
    }
    a[s+1] = x;
}
```

### [19:27] 空间与时间的权衡分析

- **空间开销**：仅一个辅助变量 $x$，空间复杂度 $O(1)$，显著优于有辅助数组的方案。
- **时间开销**：
  - 有辅助数组时，$a[q]$ 最多赋值两次（$a \to b$，$b \to a$）。
  - 无辅助时，若 $a[q]$ 是最大元素，后面有多少元素就要移动多少次（逐格后移），赋值次数显著增加。
  - 时间换空间。

### [22:58] 关键洞察：后半段的有序性并未被利用

**教学动作**：引导学生发现一个深层事实。

- 回顾算法逻辑：每次将 $a[i]$ 与前面有序段比较并插入。
- **即使 $a[q+1 \ldots r]$ 是无序的，算法仍然正确**——因为每次只取一个元素与前面有序段比较，后半段本身的顺序不影响最终结果。
- 这个条件（后半段有序）在算法中**根本没被用上**。

### [25:32] 从合并算法到插入排序

**教学动作**：利用上一步的洞察，自然过渡到排序算法。

- 既然后半段可以是无序的，任何一个数组 $a[1 \ldots n]$ 可以看作：
  - $a[1]$ 单独一个元素，自然有序（视作 $p=1, q=1$）。
  - $a[2 \ldots n]$ 为无序段（视作 $r=n$）。
- 调用上述合并算法：每次将无序段的第一个元素插入到前面的有序段中，有序段逐渐变长。
- **这就是插入排序（Insertion Sort）**。对应教材（待核对：约第 1.6 节）。

**[29:33] 插入排序参数替换：**

- $p = 1$，$q = 1$，$r = n$，外层 $i$ 从 2 到 $n$。

### [30:48] 插入排序复杂度分析

**教学动作**：板书推导比较次数与赋值次数的量级。

| $i$ | 最坏比较次数 | 最坏赋值次数 |
|-----|------------|------------|
| 2   | 1          | $1+1$      |
| 3   | 2          | $2+1$      |
| 4   | 3          | $3+1$      |
| ... | ...        | ...        |
| $n$ | $n-1$      | $(n-1)+1$  |

- **比较次数**：$1 + 2 + \cdots + (n-1) = \frac{n(n-1)}{2}$，量级为 $O(n^2)$。
- **赋值次数**：$\frac{n(n-1)}{2} + (n-1)$，量级也为 $O(n^2)$。

> **对比**：有辅助数组的合并只需 $O(n)$ 时间，空间换时间；插入排序以时间换空间，复杂度变为 $n^2$ 量级。

- **空间复杂度**：$O(1)$（仅一个辅助变量 $x$）。

## 关键概念

| 概念 | 说明 |
|------|------|
| **就地合并（In-place Merge）** | 不使用辅助数组，通过元素后移实现有序段合并 |
| **极端情况验证法** | 用最大/最小值测试算法正确性，再推广到一般情形。朱老师反复使用此法，值得学习 |
| **插入排序（Insertion Sort）** | 将无序段元素逐个插入到有序段的正确位置 |
| **时间-空间权衡** | 有辅助时 $O(n)$ / $O(n)$；无辅助时 $O(n^2)$ / $O(1)$ |
| **大O记号** | 描述算法时间复杂度的渐近上界（本节初步提及，后续会正式讲） |

## 要点详述

### 1. 单元素合并算法的极端情况验证

朱老师在本节课中多次强调**用极端情况验证算法**的方法论：

1. **$x$ 最大**（大于有序段所有元素）：`while` 不进入，$x$ 保持在原位。算法需正确处理，注意 `break` 的位置。
2. **$x$ 最小**（小于有序段所有元素）：`while` 遍历全部退出（$s$ 变成 $p-1$），`a[s+1]` 即 `a[p]` 处需补上 $x$。
3. 两种极端正确 + 逻辑自洽 → 中间情况自动正确。

### 2. "条件未充分利用"的洞察

算法并不要求后半段有序——这是本节课最关键的思维转折点。这个洞察将"合并"问题转化为"排序"问题：
- 任何一个数组，第一个元素 $a[1]$ 自然有序。
- 后续元素逐个插入，与插入排序等价。

### 3. 复杂度计算细节

- **分析粒度**：不看你下标操作（$i++, s--$），只看元素赋值（`a[s+1] = a[s]`）和元素比较（`a[s] > x`）。
- **赋值永远比比较多一次**：因为每个比较结果都要对应一次赋值（要么在 `if` 里移位，要么在循环外放入 $x$），外加最终写入 $x$ 的一次。
