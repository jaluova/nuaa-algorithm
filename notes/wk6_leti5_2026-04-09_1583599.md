# 第6周第5节 · 快速排序算法

**日期:** 2026-04-09 | **教师:** 朱友文

## 本节主线

从寻找第k小元素的划分思路自然过渡到快速排序。教师详细讲解了快排的拆分(Split)过程——将数组按主元划分为小于等于和大于两部分，然后将主元交换到正确位置，递归排序左右子数组。重点分析了快速排序平均情况下的比较次数递推式，通过数学推导得出平均时间复杂度为O(n log n)，并讨论了最坏情况（已有序数组退化为O(n^2)）及其应对策略（随机选主元）。

## 关键概念

- **拆分元素(主元/pivot)**：快排中用于划分数组的基准值，最简单的选法是选当前待排序段的第一个元素
- **拆分(Split)算法**：将数组按主元划分为小于等于和大于两部分的线性时间过程，是快排的核心子程序
- **比较次数递推式**：C(n) = n-1 + (1/n)∑[C(w-1)+C(n-w)]，描述平均情况下比较次数的递归关系
- **基本运算**：分析算法量级时选取的基准操作，快排中以比较次数为基本运算，赋值次数不超过其常数倍
- **D(n)变换技巧**：定义D(n)=C(n)/(n+1)来简化递推式，是求解此类递推的常见数学技巧

## 要点详述

### 拆分算法的实现细节

拆分过程维护两个指针i和j [07:28-16:03]：

1. 取`x = A[l]`作为主元
2. `i = l`（分界线，i及之前的元素<=x）
3. `j`从`l+1`遍历到`h`：
   - 若`A[j] > x`：不做任何操作，j直接后移
   - 若`A[j] <= x`：`i++`，交换`A[i]`与`A[j]`
4. 遍历结束后交换`A[i]`与`A[l]`，将x归位
5. 返回拆分位置i

时间复杂度：循环遍历n-1个元素，每次做一次比较，赋值不超过比较次数的3倍 [19:27-19:51]。

### 平均情况分析的推导要点

递推式化简的关键步骤 [24:50-36:50]：

1. 初始：C(n) = n-1 + (1/n)∑[C(w-1) + C(n-w)], w=1到n
2. 注意到∑C(w-1) = ∑C(n-w)（w从1到n时两者相同）
3. 化简为：C(n) = n-1 + (2/n)∑C(w-1)
4. 两边乘n：nC(n) = n(n-1) + 2∑C(w-1)
5. 写出n-1的情形并相减，得到：(n+1)C(n) = (n+1)C(n-1) + 2(n-1)
6. 定义D(n) = C(n)/(n+1)，得D(n) = D(n-1) + 2(n-1)/[n(n+1)]
7. 展开最终得D(n) = O(log n)，故C(n) = O(n log n)

### 最坏情况与改进

最坏情况发生在每次划分都极不平衡时 [48:08-49:58]：原本有序的数组，每次选第一个元素为主元，导致一侧恒为0、另一侧恒为n-1。此时时间复杂度退化为O(n^2)。改进方法：随机选取主元，可大幅降低遇到最坏情况的概率。
