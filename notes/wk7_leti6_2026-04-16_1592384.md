# 第7周第6节 · 矩阵链乘法：最优结合顺序与动态规划 O(n³)

**日期:** 2026-04-16 | **教师:** 朱友文

## 本节主线

本节课延续矩阵链乘法的讨论，首先用具体算例对比两种不同结合顺序的标量乘法次数——(M₁×M₂)×M₃ 需 ~400 次，而 M₁×(M₂×M₃) 仅需 ~80 次，相差约 5 倍，由此引出"寻找最优结合顺序"的必要性。随后分析 $n$ 个矩阵的所有可能加括号方式的数量，引入卡特兰数（Catalan numbers），指出其增长速度超过指数级别（$\Omega(4^n / n^{1.5})$），因此穷举不可行。核心部分是设计动态规划算法：用 $r[1..n+1]$ 紧凑存储所有矩阵的行列信息；定义 $C[i][j]$ 为计算 $M_i \cdots M_j$ 所需的最少标量乘法次数；推导递推式 $C[i][j] = \min_{i<k \leq j}\{C[i][k-1] + C[k][j] + r[i] \cdot r[k] \cdot r[j+1]\}$；通过在二维表中分析依赖关系（同一行左侧 + 同一列下方），得出必须按对角线逐条填充的遍历顺序；最终写出三重循环算法，时间复杂度 $O(n^3)$。

## 关键概念

- **矩阵链乘法问题（Matrix Chain Multiplication）**：给定 $n$ 个可连续相乘的矩阵 $M_1, M_2, \dots, M_n$，求一种加括号的结合顺序，使得计算整个连乘积所需的标量乘法次数最少。
- **标量乘法次数**：两个矩阵 $A_{p \times q}$ 与 $B_{q \times r}$ 相乘，结果矩阵有 $p \times r$ 个元素，每个元素需 $q$ 次标量乘法，共计 $p \cdot q \cdot r$ 次。
- **结合方式数 / 卡特兰数（Catalan Number）**：$n$ 个矩阵的加括号方式数 $f(n) = C_{n-1}$（第 $n-1$ 个卡特兰数），递推式为 $f(n) = \sum_{k=1}^{n-1} f(k) \cdot f(n-k)$，下界 $\Omega(4^n / n^{1.5})$。增长速度超过 $2^n$，因此穷举不可行。
- **紧凑存储（$r$ 数组）**：利用 $M_i$ 的列数等于 $M_{i+1}$ 的行数的相容条件，用一个 $n+1$ 长的数组 $r[1..n+1]$ 存储全部 $n$ 个矩阵的行列信息——$r[i]$ 是 $M_i$ 的行数，$r[i+1]$ 同时是 $M_i$ 的列数和 $M_{i+1}$ 的行数，$r[n+1]$ 是 $M_n$ 的列数。
- **状态 $C[i][j]$**：从 $M_i$ 连续乘到 $M_j$ 所需的最少标量乘法次数。是矩阵链乘法 DP 的核心状态量。
- **最优子结构**：$M_i \cdots M_j$ 的最优结合方式中，在 $k-1$ 与 $k$ 之间分开后，前半段 $M_i \cdots M_{k-1}$ 和后半段 $M_k \cdots M_j$ 各自也必须是最优结合的——这是递推式成立的理论基础。
- **递推式**：$C[i][j] = \min_{i < k \leq j}\{ C[i][k-1] + C[k][j] + r[i] \cdot r[k] \cdot r[j+1] \}$，边界 $C[i][i] = 0$。与传统"只做加法"的 DP 递推不同，这里引入了 $\min$ 算子对分割点 $k$ 的枚举。
- **对角线遍历（Diagonal Fill Order）**：因 $C[i][j]$ 依赖"同行左侧"和"同列下方"元素，只有按 $d = j-i$ 从小到大的对角线顺序填充，才能保证每个 $C[i][j]$ 计算时所需元素均已就绪。
- **$O(n^3)$ 时间复杂度**：外层对角线条数 $O(n)$，中层每对角线元素数 $O(n)$，内层枚举分割点 $O(n)$，三重循环合计 $O(n^3)$——远低于穷举的指数复杂度。

## 要点详述

### 一、两种结合顺序的算例对比 [00:00]

教师延续上一讲的矩阵链乘法例子（三个矩阵 $M_1$、$M_2$、$M_3$），详细计算第二种结合顺序 $M_1 \times (M_2 \times M_3)$ 的标量乘法次数 [00:25-00:57]：

- **先算 $M_2 \times M_3$**：$M_2$ 为 $2 \times 10$，$M_3$ 为 $10 \times 2$，相乘需 $2 \times 10 \times 2 = 40$ 次。乘得的结果是一个 $2 \times 2$ 矩阵（共 4 个元素，每个元素需 10 次乘法）。
- **再算 $M_1 \times (M_2 M_3)$**：$M_1$ 为 $10 \times 2$，乘以 $2 \times 2$ 的结果矩阵，需 $10 \times 2 \times 2 = 40$ 次。
- **总计**：$40 + 40 = 80$ 次。

对比上一节计算的第一种顺序 $(M_1 \times M_2) \times M_3$ 约需 400 次，两种顺序相差约 **5 倍** [00:57-01:04]。

> 注：transcript 中部分数字存在口音/转录偏差（如 "44" 实为 "40"，"M1 是 4×2" 可能为 "M1 是 10×2"），以上数值系根据教师所述两种顺序 400 vs 80 的 5 倍差异反推确认。

教师强调：当矩阵行数、列数悬殊较大时，不同结合顺序的效率差异尤为显著 [01:08-01:21]。现实中可能有几十甚至上万个矩阵连乘，必须寻找最优的结合顺序以最小化计算代价 [01:45-02:12]。

### 二、结合方式计数与卡特兰数 [02:13]

直观思路"把所有可能顺序都算一遍再比较"很快不可行，因为可能的方式数增长极快 [02:28-02:44]：

- 2 个矩阵：仅 1 种结合方式
- 3 个矩阵：2 种
- 4 个矩阵：5 种
- 5 个矩阵：14 种
- 6 个矩阵：42 种 [03:57-06:13]

这个数列的增长速度**超过指数级别** [04:03-04:11]。

**递推公式** [04:32-05:19]：设 $f(n)$ 为 $n$ 个矩阵的加括号方式数。考虑最后一步乘法在 $M_k$ 与 $M_{k+1}$ 之间分开（$k$ 从 $1$ 到 $n-1$），前半段有 $f(k)$ 种方式，后半段有 $f(n-k)$ 种方式，因此：

$$f(n) = \sum_{k=1}^{n-1} f(k) \cdot f(n-k)$$

其中 $f(1) = f(2) = 1$。

**卡特兰数** [05:48-05:58]：$f(n) = C_{n-1}$（第 $n-1$ 个卡特兰数），其闭合形式为：

$$f(n) = \frac{1}{n}\binom{2n-2}{n-1}$$

**增长速度的下界** [06:18-06:41]：

$$f(n) = \Omega\left(\frac{4^n}{n^{1.5}}\right)$$

$4^n = (2^n)^2$，除以 $n^{1.5}$ 后仍远大于 $2^n$。也就是说，当 $n$ 稍大时，穷举所有结合方式的代价远超指数级别，绝不可行 [06:42-07:17]。

### 三、问题转化与多项式时间目标 [07:42]

既然枚举所有结合顺序是指数量级，必须寻找多项式时间算法 [07:44-08:09]。教师提出策略：

1. 先用动态规划求出**最优结合顺序所对应的最少标量乘法次数**（一个数值）；
2. 在计算过程中附带记录分割点信息，后续可反推出具体的结合顺序 [09:00-09:37]。

接下来的核心就是设计这个动态规划算法。

### 四、矩阵维度信息的紧凑存储 [10:05]

$n$ 个矩阵 $M_1, M_2, \dots, M_n$，每个矩阵有行数和列数两个维度。如果直接存储需 $2n$ 个数。但利用矩阵相乘的相容性——**前一矩阵的列数必然等于后一矩阵的行数**——可以用 $n+1$ 个数的数组 $r[1..n+1]$ 紧凑存储 [10:40-11:01]：

- $r[1]$：$M_1$ 的行数
- $r[2]$：$M_1$ 的列数 $=$ $M_2$ 的行数
- $r[i]$：$M_{i-1}$ 的列数 $=$ $M_i$ 的行数
- $r[n+1]$：$M_n$ 的列数 [13:38-13:55]

这样，$M_i$ 的行数为 $r[i]$，列数为 $r[i+1]$。任意两个矩阵相乘时，只需从 $r$ 数组中读取对应下标即可 [14:40-14:52]。

### 五、状态定义与初始值 [15:14]

**记号约定** [16:12-17:13]：用 $M_{ij}$ 表示 $M_i M_{i+1} \cdots M_j$ 这一串矩阵的连乘结果。$M_{1n}$ 即为 $M_1 M_2 \cdots M_n$。

**状态定义** [17:19-18:24]：定义 $C[i][j]$ 为计算 $M_{ij}$（即 $M_i$ 乘到 $M_j$）这一串矩阵连乘积所需的最少标量乘法次数：

$$C[i][j] = \text{计算 } M_i M_{i+1} \cdots M_j \text{ 的最少标量乘法次数}$$

**目标值**：$C[1][n]$ [18:27-18:36]。

**初始值**：当 $i=j$ 时仅有一个矩阵，无需任何乘法，故 $C[i][i] = 0$ [18:44-18:57]。当 $j=i+1$（仅两个相邻矩阵）时，可直接算出作为初始值或由递推式自然推出 [19:03-19:14]。

### 六、递推关系推导 [19:57]

无论矩阵链有多长，最后一步乘法总是**两个矩阵相乘**——前面若干个矩阵已经乘好，后面若干个矩阵也已经乘好，最后这两块再合在一起 [20:17-20:38]。这正是建立递推关系的关键。

设在 $M_{k-1}$ 与 $M_k$ 之间分开（即最后一步将 $M_i \cdots M_{k-1}$ 的结果与 $M_k \cdots M_j$ 的结果相乘），其中 $k$ 满足 $i < k \leq j$ [22:02-22:27]。

对某个确定的 $k$ [22:28-25:11]：

1. **前半段代价**：计算 $M_i \cdots M_{k-1}$ 最少需 $C[i][k-1]$ 次
2. **后半段代价**：计算 $M_k \cdots M_j$ 最少需 $C[k][j]$ 次
3. **最后一步合并代价**：前半段结果是 $r[i] \times r[k]$ 矩阵，后半段结果是 $r[k] \times r[j+1]$ 矩阵，合并需 $r[i] \cdot r[k] \cdot r[j+1]$ 次

三项相加即为以 $k$ 为分界点时的总代价。对所有可能的 $k$（从 $i+1$ 到 $j$）取最小值，即得递推式 [25:48-27:35]：

$$C[i][j] = \min_{i < k \leq j} \Big\{ C[i][k-1] + C[k][j] + r[i] \cdot r[k] \cdot r[j+1] \Big\}$$

这个递推式不再是简单的加法，还包含了 $\min$ 算子和对 $k$ 的枚举，是更复杂的 DP 递推形式 [26:14-26:28]。

### 七、二维表依赖分析与填充顺序 [27:35]

将 $C[i][j]$ 画成 $n \times n$ 的二维表 [28:24-29:00]：

- **行号** $i = 1,2,\dots,n$
- **列号** $j = 1,2,\dots,n$
- **左下三角**（$i > j$）：无意义（不能从 $i$ 倒退到 $j$）
- **对角线**（$i=j$）：初始值，全为 $0$ [29:00-29:07]
- **右上角**（$i=1, j=n$）：目标值 $C[1][n]$ [29:14-29:19]
- **中间区域**（$i < j$）：待计算 [29:39-29:46]

**依赖关系分析** [29:57-36:44]：

对于 $C[i][j]$，枚举 $k$ 时：
- $C[i][k-1]$：行号 $i$ 相同，列号 $k-1 \leq j-1 < j$ — 即**同一行、左侧**的元素，范围一直延伸到对角线为止 [34:40-34:57]
- $C[k][j]$：列号 $j$ 相同，行号 $k \geq i+1 > i$ — 即**同一列、下方**的元素，范围一直延伸到对角线为止 [36:07-36:19]

因此，计算 $C[i][j]$ 需要：同行左侧的所有元素 + 同列下方的所有元素均已就绪 [36:29-36:34]。

**填充顺序** [37:05-38:50]：按上述依赖关系，**不能逐行填充，也不能逐列填充**，必须**按对角线逐条填充**：

- 第 0 条对角线 $d=0$（$i=j$）：初始值，已知
- 第 1 条对角线 $d=1$（如 $C[1][2], C[2][3], \dots$）：只依赖对角线上的元素（已知），可计算 [37:33-37:40]
- 完成 $d=1$ 后才能计算 $d=2$，依此类推 [38:12-38:30]

同一条对角线上，$j-i = d$ 是固定常数 [39:14-39:21]。最大对角线差值为 $n-1$（对应于 $C[1][n]$）。

### 八、算法伪代码与时间复杂度 [39:56]

**数据结构**：
- 输入数组 $r[1..n+1]$：已知，存储所有矩阵的行列信息
- 二维数组 $C[1..n][1..n]$：用于 DP 填表

**初始化** [40:26-40:52]：将所有 $C[i][i]$ 置为 $0$。

**三重循环** [41:03-48:35]：

```
for d = 1 to n-1 do                     // 外层：走对角线，d = j - i
    for i = 1 to n-d do                 // 中层：对角线上的行号
        j = i + d                        // 列号由行号和差值确定
        // 初始化：取第一个 k 对应的候选值
        s = C[i][i] + C[i+1][j] + r[i]·r[i+1]·r[j+1]
        for k = i+2 to j do             // 内层：枚举分割点
            t = C[i][k-1] + C[k][j] + r[i]·r[k]·r[j+1]
            if t < s then s = t
        end for
        C[i][j] = s
    end for
end for
return C[1][n]
```

**内层细节** [45:02-48:02]：对每个 $k$ 计算候选代价 $t$（三个分量相加），与当前最优 $s$ 比较，若 $t < s$ 则更新 $s$。内层循环结束后，$s$ 即为 $C[i][j]$。

**时间复杂度分析** [48:36-48:58]：

- 外层：$d$ 从 $1$ 到 $n-1$，共 $O(n)$
- 中层：每对角线元素数 $\leq n$，共 $O(n)$
- 内层：枚举 $k$ 最多 $O(n)$
- 总复杂度：$O(n^3)$，是多项式时间，远优于穷举的指数复杂度。
