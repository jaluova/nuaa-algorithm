## 关键概念

- **求和式渐进分析**：算法循环结构中各轮代价求和常产生 $\sum f(j)$ 形式，需用 $n$ 的简洁表达式刻画其量级
- **不等式放缩法**：通过放大/缩小求和项来夹逼上下界，依赖经验和技巧，复杂表达式不易操作
- **积分近似法 (Integral Approximation)**：将离散求和 $\sum f(j)$ 视作阶梯矩形面积之和，与连续函数定积分 $\int f(x)dx$ 比较得到上下界的系统化方法
- **矩形构造（递减函数）**：对 $f(j)$ 在 $x=j$ 处向左（或向右）构造宽1的矩形，其面积为 $f(j)$；求和式等价于所有矩形面积之和
- **定界方向（递减 vs 递增）**：单调递减时矩形可置于曲线下方（得积分上界）或上方（得积分下界）；单调递增时方向恰好交换
- **积分无意义处理**：当 $m-1$ 代入被积函数后出现无定义值（如 $\frac{1}{0}$、$\log 0$）时，将第一项单独提出，从有定义的下标开始套用积分公式

## 要点详述

### 渐进记号回顾：$f(n)$ 与 $f(n+1)$ 不一定同阶

上节课讨论了 $f(n)$ 与 $f(n+1)$ 互相作为渐进上下界的前两种情况。本节补充第三种——当 $f(n)=n!$ 时：

$$\frac{n!}{(n+1)!} = \frac{1}{n+1} \to 0 \quad (n \to \infty)$$

这意味着 $f(n+1)$ 不再是 $f(n)$ 的上界，两者不满足常数倍的大小 $\Theta$ 关系。但对于多项式、指数函数等常见情形，$f(n)$ 与 $f(n+1)$ 依然同阶。

### 为什么需要分析求和式

算法的时间复杂度分析中经常出现求和式，典型场景是循环结构：算法中有 $n$ 轮循环，第 $j$ 轮的代价为 $f(j)$，总代价为 $\sum_{j=1}^{n} f(j)$。这种表达式需要用一个仅含 $n$ 的简洁形式给出量级估计。

常见例子：$\sum_{j=1}^{n} \log j$，$\sum_{j=1}^{n} \frac{n}{j}$ 等，它们不是简单的等差/等比数列，不能直接套用已知求和公式。

### 不等式放缩法演示：$\sum \log j$

以 $f(n) = \sum_{j=1}^{n} \log j$ 为例：

**上界**：将每一项放大为 $\log n$（因为 $j \le n$，$\log$ 单调递增）：
$$f(n) \le \sum_{j=1}^{n} \log n = n \log n$$

**下界**：丢弃 $j < n/2$ 的项，再将剩余项中 $\log j$ 缩小为 $\log(n/2)$：
$$f(n) \ge \sum_{j=\lfloor n/2 \rfloor}^{n} \log\left(\frac{n}{2}\right) \approx \frac{n}{2}(\log n - 1)$$

两者均为 $\Theta(n \log n)$ 量级，证得 $f(n) = \Theta(n \log n)$。

> 这种放缩技巧对 $\log$ 求和尚可，但对 $\sum \frac{n}{j}$ 这类表达式，放缩就远没有那么直观了。

### 积分近似法的核心思想

给定求和式 $f(n) = \sum_{j=m}^{n} f(j)$。将每一项 $f(j)$ 想象成一个矩形：宽度为 1，高度为 $f(j)$，所有矩形面积之和恰好等于求和式。

在 $xy$ 平面上画出 $y=f(x)$ 的连续曲线。当 $f(x)$ 单调时，这些阶梯矩形与曲线围成的区域有明确的大小关系，从而可以用定积分来夹逼求和式。

- **不需要不等式技巧**：只需会计算 $\int f(x)dx$
- **上下界通常同阶**：因为定积分的上、下限只差常数偏移

### 单调递减函数的积分界

设 $f(x)$ 在 $[m, n]$ 上单调递减。

**上界**：在每个 $x=j$ 处向左构造矩形（宽1，高 $f(j)$），矩形位于曲线**下方**。所有矩形面积之和 $f(n)$ 小于从 $m-1$ 到 $n$ 的定积分：
$$f(n) \le \int_{m-1}^{n} f(x)\,dx$$

**下界**：在每个 $x=j$ 处向右构造矩形（宽1，高 $f(j)$），矩形覆盖在曲线**上方**。所有矩形面积之和大于从 $m$ 到 $n+1$ 的定积分：
$$f(n) \ge \int_{m}^{n+1} f(x)\,dx$$

综合得：
$$\int_{m}^{n+1} f(x)\,dx \le \sum_{j=m}^{n} f(j) \le \int_{m-1}^{n} f(x)\,dx$$

### 单调递增函数的积分界

设 $f(x)$ 单调递增。矩形构造方向与递减情况相反，结果上、下界的积分限互换：

$$\int_{m-1}^{n} f(x)\,dx \le \sum_{j=m}^{n} f(j) \le \int_{m}^{n+1} f(x)\,dx$$

教师强调：**不要死记硬背公式**，遇到具体问题时自己画出 $f(x)$ 曲线和矩形，一眼就能看出积分应该从哪积到哪。

### 实例一：$\sum_{j=1}^{n} j^k$

$f(x)=x^k$ 单调递增。不定积分 $\int x^k dx = \frac{x^{k+1}}{k+1}$。

代入递增积分界公式：
- 下界：$\int_{0}^{n} x^k dx = \frac{n^{k+1}}{k+1}$
- 上界：$\int_{1}^{n+1} x^k dx = \frac{(n+1)^{k+1}}{k+1}$

两者均为 $\Theta(n^{k+1})$，即 $\sum_{j=1}^{n} j^k = \Theta(n^{k+1})$。

### 实例二：$\sum_{j=1}^{n} \frac{n}{j}$

常数 $n$ 可提出：$f(n) = n \cdot \sum_{j=1}^{n} \frac{1}{j}$，核心是分析 $\sum_{j=1}^{n} \frac{1}{j}$。

$f(x)=\frac{1}{x}$ 单调递减。若直接套用递减上界公式 $\int_{m-1}^{n} \frac{1}{x} dx$，当 $m=1$ 时得到 $\int_{0}^{n} \frac{1}{x}dx$，在 $x=0$ 处无意义。

**解决**：将 $j=1$ 这一项拆出：
$$\sum_{j=1}^{n} \frac{1}{j} = 1 + \sum_{j=2}^{n} \frac{1}{j}$$

对后半部分从 $m=2$ 套用积分界，此时 $m-1=1$，积分不再出现奇点。

### 实例三：$\sum_{j=1}^{n} \log j$

$f(x)=\log x$ 单调递增。但 $j=1$ 时 $m-1=0$，$\log 0$ 无意义。不过 $\log 1 = 0$，因此可以直接写成：
$$\sum_{j=1}^{n} \log j = \sum_{j=2}^{n} \log j$$

从 $m=2$ 套用递增积分界公式即可，无需不等式技巧就得到与前面放缩法一致的结果。

### 课堂练习：$\sum \frac{\log j}{j}$

布置练习题：对 $f(n) = \sum_{j=1}^{n} \frac{\log j}{j}$，已知不定积分公式，证明 $f(n) = O(n \log n)$。

本题**只需证明上界**（大 $O$），不必同时求上界和下界。学生独立完成，不得代写，完成后即可离堂。
