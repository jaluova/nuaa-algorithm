## 关键概念

- **笛卡尔积 (Cartesian Product)**：$A \times B = \{(a,b) \mid a \in A, b \in B\}$，二元组有序，有方向性
- **关系 (Relation)**：笛卡尔积的任意子集，用于形式化表达事物之间的关联
- **自反性 (Reflexivity)**：对任意元素 $a$，$(a,a)$ 属于该关系——自己与自己有关
- **对称性 (Symmetry)**：若 $(a,b)$ 属于关系，则 $(b,a)$ 也必在关系中
- **传递性 (Transitivity)**：若 $(a,b)$ 和 $(b,c)$ 都在关系中，则 $(a,c)$ 也在关系中
- **等价关系 (Equivalence Relation)**：同时满足自反、对称、传递的关系——大Θ是等价关系，大O和大Ω不是
- **复杂度等价类**：在大Θ关系下互相等价的函数集合，用最简洁表达式（如 $n^2$）代表整个类
- **小o (Little-o)**：$f(n)=o(g(n))$ 表示 $f$ 的量级严格低于 $g$，$\lim f/g = 0$——用于比较不同等价类
- **最优算法**：当算法时间复杂度的上界恰好等于该问题已被证明的下界（忽略常数因子）时，称该算法为最优算法
- **基本运算 (Basic / Essential Operation)**：出现次数（或其常数倍）超过其他所有运算的元运算，可用它单独估算算法量级
- **特征方程法**：求解 $f(n)=a_1 f(n-1)+a_2 f(n-2)$ 型递推式的标准方法，$x^2-a_1x-a_2=0$ 的根决定通解形式

## 要点详述

### 笛卡尔积与关系

两个集合 $A$ 与 $B$ 的笛卡尔积 $A \times B$ 是全体有序二元组 $(a,b)$（其中 $a \in A, b \in B$）构成的集合。注意笛卡尔积有方向性——$A \times B$ 与 $B \times A$ 一般不相等。

关系 $R$ 定义为笛卡尔积的一个子集：$R \subseteq A \times B$。这就意味着关系就是挑选出笛卡尔积中那些"确实有关系"的二元组。例如：
- 师生关系：$A$ 是所有老师，$B$ 是所有学生，$(a,b) \in R$ 当且仅当学生 $b$ 听过老师 $a$ 的课
- 国家相邻：$A = B =$ 所有国家，$(a,b) \in R$ 当且仅当 $a$ 与 $b$ 国界相邻
- 数值比较关系（$>,\ <,\ \ge$ 等）同样可用此法定义

特别地，当 $A = B$ 时，关系定义在同一个集合上，称为该集合上的关系。

### 渐近符号作为关系

将大O、大Ω、大Θ分别视作函数表达式之间的二元关系：
- $r_1$ (大O关系)：$(f,g) \in r_1$ 当且仅当 $f(n) = O(g(n))$
- $r_2$ (大Ω关系)：$(f,g) \in r_2$ 当且仅当 $f(n) = \Omega(g(n))$
- $r_3$ (大Θ关系)：$(f,g) \in r_3$ 当且仅当 $f(n) = \Theta(g(n))$

### 等价关系与三个渐近记号的性质

等价关系必须同时满足三个性质：

| 性质 | 大O ($r_1$) | 大Ω ($r_2$) | 大Θ ($r_3$) |
|---|---|---|---|
| 自反：$f = O(f)$? | ✓ | ✓ | ✓ |
| 对称：$f = O(g) \Rightarrow g = O(f)$? | ✗ | ✗ | ✓ |
| 传递：$f = O(g) \land g = O(h) \Rightarrow f = O(h)$? | ✓ | ✓ | ✓ |
| 是等价关系? | ✗ | ✗ | ✓ |

大Θ对称性的直观理解：若 $f = \Theta(g)$，从极限角度看 $\lim f/g$ 收敛到一个正常数 $c > 0$，则 $\lim g/f = 1/c > 0$ 也是正常数，故 $g = \Theta(f)$。

因此只有大Θ能构成等价关系，这也是为什么我们可以用它来划分**复杂度等价类**。

### 复杂度等价类与小o

在大Θ等价关系下，$2n^2$、$3n^2 - 2n + 5$、$n^2$ 等互相等价，同属 $n^2$ 等价类。表示时一律选用最简洁的形式（去掉常数系数和低阶项）。

**小o的定义**：$f(n) = o(g(n))$ 当且仅当对任意常数 $c > 0$，存在 $n_0$ 使得对所有 $n > n_0$ 有 $f(n) < c \cdot g(n)$。等价于：

$$\lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$$

与大O/大Ω/大Θ的区别：
- 大O/大Ω/大Θ 是两个具体函数表达式之间的关系
- 小o 是两个等价类之间的关系——比较的是"级别"而非具体函数
- $f = o(g)$ 意味着 $f$ 的增长率严格低于 $g$

常见等价类的递增顺序（从左到右开销越来越高）：
$$1 \quad < \quad \log n \quad < \quad n \quad < \quad n\log n \quad < \quad n^2 \quad < \quad 2^n \quad < \quad n!$$

### 算法分析的意义

1. **算法选型依据**：同一问题常有多种算法，分析结果帮助在不同场景中选择最合适的
2. **分析辅助设计**：先设计"粗糙"版本，通过分析找出瓶颈（耗时最多的模块），据此优化改进——形成"设计→分析→再设计"的迭代
3. **可行性预判**：分析确认算法在时间和空间上可行，才值得投入实现——避免实现了一个理论上无用的算法

### 复杂度分析的几点说明

- **常数因子被忽略**：用渐近符号分析时，$10^{-1}n^2$ 和 $10^6n^2$ 都是 $O(n^2)$。这只能在 $n$ 非常大（常数影响被稀释）时才有指导意义
- **小规模问题不适用**：对3个数字排序，直接比较即可，无需考虑复杂算法
- **同量级不等于同开销**：同样是 $\Theta(n\log n)$ 的排序算法，常数差异可达上万倍，工程选型仍需实测

### 时间开销与空间开销的关系

$$T_A(n) = \Omega(S_A(n))$$

时间复杂度的量级不低于空间复杂度的量级。原因：算法每分配一个内存单元，至少需要执行一次读或写操作，而这些读写本身的耗时会被计入时间开销。时间 = 空间相关操作 + 纯计算操作，所以时间不可能比空间增长得更慢。

- 二分查找：$T(n) = \Theta(\log n)$，$S(n) = O(1)$ —— 无额外辅助数组
- 有序段合并：$T(n) = \Theta(n)$（复制两轮 + 比较），$S(n) = \Theta(n)$（辅助数组）

### 最优算法

一个问题被证明其任何算法的下界为 $\Omega(f(n))$，若有人设计出一个上界为 $O(f(n))$（即恰好 $f(n)$ 量级）的算法，则该算法称为该问题的**最优算法**。

注意：
- "最优"指量级最优（忽略常数因子），并非没有更优的可能——常数因子仍可优化
- 证明下界 $\Omega(f(n))$ 通常很困难（例如基于比较的排序下界 $\Omega(n\log n)$ 需要信息论证明）
- 若无特别说明，"最优算法"默认指的即是量级最优

### 基本运算

当算法涉及多种元运算（比较、赋值、算术运算等），若其中某一种运算的出现次数（或其常数倍）始终超过其他所有运算，则该运算可视为**基本运算**。

例如两个有序段的合并中，赋值次数始终不少于比较次数，故只统计赋值次数即可正确估计渐近量级——比较的贡献只增加一个常数倍，不影响量级。

选取基本运算的目的：将复杂度分析简化为只统计一种运算的次数，大幅降低分析难度。

### 递推关系的求解（特征方程法）

对于形如 $f(n) = a_1 f(n-1) + a_2 f(n-2)$ 的二阶齐次线性递推式，给定初值 $f(1)$ 和 $f(2)$：

1. **写特征方程**：$x^2 - a_1x - a_2 = 0$
2. **求根**：解得两个根 $r_1, r_2$

3. **分情形**：
   - 若 $r_1 \neq r_2$（两个不等实根），通解为：
     $$f(n) = c_1 \cdot r_1^n + c_2 \cdot r_2^n$$
   - 若 $r_1 = r_2 = r$（重根），通解形式不同（本讲未展开完整）

4. **定常数**：代入 $n=1$ 和 $n=2$ 的初值，形成关于 $c_1, c_2$ 的二元一次方程组，解出 $c_1, c_2$
5. **得闭式**：将 $c_1, c_2, r_1, r_2$ 代回通解即得 $f(n)$ 的显式表达式
